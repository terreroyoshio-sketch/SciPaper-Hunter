## 1. 逐图结构记录

### 图2 · 四步横带（technical roadmap）

- **reading direction**：整体上→下（4 个带），带内左→右
- **panel structure**：4 个虚线分区带；带间 1 枚粗块箭头（绿）
- **layout grid**：带内左侧约 60% 为语义容器链（3–5 个，同族等宽等距），右侧约 35% 内嵌结果小图；全图网格对齐
- **visual hierarchy**：编号徽章（深红圆）→ 带标题（深红粗体）→ 语义容器 → 内嵌小图
- **container style**：圆角矩形；低饱和填充 + 中饱和描边；带框为细虚线
- **arrow style**：节点间小箭头（实心三角、0.8–1 pt）；带间粗块箭头承担"阶段推进"语义
- **line style**：0.5–1 pt；虚线用于带框与阈值参考线
- **color system**：绿=数据/输入、蓝紫=方法、粉橙=结果、深红=编号与标题；同族同色全文一致
- **typography**：无衬线，按印幅约 6.5–8 pt；标题加粗；节点内 2–5 词
- **amount of text**：极少；语义主要由结构 + 图形承担（对应"图形为主角"要求）
- **embedded charts**：✓ 时序（双线）、散点+拟合线、阶跃序列+阈值+阴影超限区、排序横条
- **embedded maps / rasters**：无（另一参考图中存在）
- **formula usage**：✓ 公式框独立样式（条件概率表达式）
- **whitespace / border / zoning**：留白充分（≥1 倍盒高）；白底；虚线带框完成分区
- **panel labels**：①–④ 编号徽章（非 a/b/c）
- **caption dependence**：低——单图可读；细节交图注

### 图3 · hub-and-spoke 方法框架

- **reading direction**：中心→四周；上部"输入/特征/传播行为"→ 中部"聚类/模型"→ 下部"归因/汇总"
- **container style**：大圆角分组框；米色（cream）底 + 白色内卡
- **embedded elements**：数据表、PCA 散点、6 个小过程线面板、模拟/实测对比柱、贡献度横条（含百分比标注）、模型结构示意
- **semantic pairs**：Measured/Simulated 成对出现的对比柱是"验证"语义的显式表达
- **typography**：无衬线；分组标题灰底加粗
- **summary band**：底部整宽汇总条承载结论性文字（3 行）
- **caption dependence**：中——表内细节需图注补充

### 图4 · a/b/c 多面板数据流

- **panel labels**：a / b / c 左上角加粗
- **color coding by data role**：输入=深绿标题条、过程=浅色、结果=浅黄、**数据分辨率=独立色族**（1° 网格=黄、500 m=粉、其他=蓝）+ 右侧**独立图例框**显式声明色块语义
- **connectors**：细箭头，以正交/短直连线为主（非对角线长线）
- **granularity**：每个处理操作一个节点——适合"数据处理流水线"型方法图；细节量高于图2
- **caption dependence**：高——节点多数需要图注解释

## 2. 横向规律（四张图的共同风格 DNA）

1. **语义容器是允许且必要的**：矩形/圆角矩形/分区面板/虚线带承载明确的信息组织功能——**有语义的框和箭头是范式，不是禁忌**。
2. **功能配色 + 显式图例**：色块承担语义（输入/方法/结果/数据层级），且图例必须显式声明。
3. **内嵌真实小图**：方法图中嵌入真实数据小图（时序/散点/柱/表）把"流程"升级为"论证"；小图必须来自真实数据。
4. **网格先行**：同族元素等宽等距；带/栏/行三级网格清晰。
5. **层级化排版**：编号徽章/标题/容器/小图四级视觉权重；标题加粗、正文小号。
6. **低饱和色阶 + 灰度可辨**：色族之间保持明度差；线条与描边承担灰度冗余。
7. **正交布线**：箭头以水平/垂直为主；跨区连接走走廊，不穿越容器主体。
8. **矢量 + 印幅字号**：这类图最终以矢量投放型印刷，字号按印幅反推（非屏幕尺寸）。

## 3. "方框+箭头"规则修正（生效版）

原《制图提示词》§17/§52/§54 把"禁止方框+箭头"写成了绝对规则，与上述参考图范式冲突。**修正为**（2026-09-28 用户确认）：

> **禁止**无语义、模板化的方框堆叠和默认流程图风格（默认 Mermaid 风、PPT SmartArt、彩色圆角卡片堆、全节点同尺寸同箭头、纯文字节点占据全部视觉主体、装饰性图标）。
> **允许**矩形、圆角矩形、分区面板、箭头、连接线、虚线区域、公式、地图、数据小图、几何示意——但**每个容器必须承担明确的信息组织功能**。
> 技术路线图优先采用"数据层—方法层—分析层—结果层"或与论文实际方法一致的层级；重要步骤应结合真实小图、公式、地图、几何对象或结果缩略图，而不是全部用文字节点表达。

**"几何叙事"仍然保留，但降为分场景建议而非全局禁令**：算法流程图（数模类）优先用与数学模型对应的几何对象（点/射线/圆/可行域/半透明交叠/轨迹）表达算法阶段；**方法框架图/技术路线图**则允许语义容器 + 箭头，前提是语义明确、非模板堆叠。
