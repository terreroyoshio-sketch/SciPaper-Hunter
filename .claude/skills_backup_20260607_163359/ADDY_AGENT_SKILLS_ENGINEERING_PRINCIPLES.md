# Addy Osmani Agent Skills — Engineering Principles

---

1. **AI coding agent 不应该无计划开写。** 每个开发阶段必须有清晰入口和质量门槛。

2. **spec 是开发入口，不是形式主义。** 没有结构化 spec 之前不写代码。

3. **plan 必须拆成可验证的小步。** 每一步有目标、影响文件、测试方式和回滚策略。

4. **build 不能顺手重构无关文件。** 一次只做一个垂直切片，不扩大修改范围。

5. **test 是完成的必要条件。** 没有测试日志，不得声称功能完成。

6. **review 要覆盖五轴：** 正确性、可读性、架构、性能、安全性。

7. **code-simplify 要删除不必要复杂度，不是做花哨重构。** 优先减少抽象层和条件分支。

8. **ship 是 go/no-go 审查，不是自动部署。** 执行后必须人工确认才能上线。

9. **code-reviewer、test-engineer、security-auditor 应在交付前并行审查。** 三个视角缺一不可。

10. **没有测试日志，不得声称测试通过。** 必须实际运行并记录结果。

11. **没有安全审计，不得声称可上线。** security-auditor 审查是 /ship 的必要条件。

12. **没有回滚策略，不得建议发布。** 任何上线前必须确认回滚方案。

13. **任何高风险 Git、部署、删除、上线行为都必须人工确认。** AI 不能替代工程判断。

14. **AI 不应抄近道。** 每个开发阶段都不可跳过，质量门槛不可降低。

15. **任何声称完成的修改都必须有验证证据。** 测试日志、审查意见、安全报告缺一不可。
