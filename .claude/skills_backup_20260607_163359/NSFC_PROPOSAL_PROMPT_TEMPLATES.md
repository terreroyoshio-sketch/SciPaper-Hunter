# NSFC 基金架构 — 提示词模板

以下模板可直接复制并在 Claude Code 中使用。

---

## 模板 1：完整国自然架构流水线

```
请使用 nsfc-proposal-architecture-pipeline。
以下是我的初步研究构想、前期工作摘要、核心文献清单和研究方案草稿。
请不要自由发挥代写，不要虚构前期数据或文献。
请依次完成关键科学问题提炼、目标内容对齐、立项依据逻辑、
方案可行性审计、前期基础映射、创新点提炼、技术路线蓝图、
400 字摘要、术语一致性校对和函评专家质询。

[在此处粘贴初步研究构想、前期数据、文献清单、研究方案]
```

---

## 模板 2：关键科学问题提炼

```
请使用 key-scientific-question-extractor。
请从以下初步研究设想和前期数据中提炼 1 到 2 句关键科学问题，
并区分它与普通技术瓶颈的差异。避免"机制尚不明确"等空泛表达。

[在此处粘贴研究摘要、前期数据、研究背景]
```

---

## 模板 3：研究目标与内容对齐

```
请使用 objective-content-alignment-planner。
请将以下关键科学问题拆解为 3 到 4 个研究目标，
并将每个目标对应到具体研究内容，输出层级矩阵，
不要写成长篇段落。

[在此处粘贴关键科学问题和初步研究内容]
```

---

## 模板 4：立项依据逻辑大纲

```
请使用 proposal-rationale-gap-locator。
请基于以下核心文献清单和关键科学问题，构建立项依据部分的
逐段逻辑大纲，遵循"宏观需求—研究进展—具体空白—本项目方案"
的漏斗结构。不得编造文献。

[在此处粘贴核心文献清单、关键科学问题、拟解决问题]
```

---

## 模板 5：研究方案可行性审计

```
请使用 feasibility-methodology-auditor。
请审查以下研究方案和实验方法，重点检查对照组、样本量、
统计方法、关键实验风险和备用方案。不要代写方案，
只输出审查报告和修改建议。

[在此处粘贴研究方案、实验方法、样本来源、分析方法]
```

---

## 模板 6：特色与创新点提炼

```
请使用 proposal-innovation-extractor。
请从以下申请书草稿中提炼 2 到 3 个实质性创新点，
并按理论概念创新、方法学创新、机制体系创新或应用创新分类。
拒绝"首次开展"式表面创新。

[在此处粘贴申请书草稿、前期数据、对比文献]
```

---

## 模板 7：前期基础组织

```
请使用 preliminary-work-coherence-planner。
请根据以下前期数据和研究内容，建立前期图表与拟开展研究内容
之间的映射关系，并说明每张图表如何证明可行性或提示关键科学问题。

[在此处粘贴前期工作数据、图表摘要、研究内容、关键科学问题]
```

---

## 模板 8：技术路线图文本蓝图

```
请使用 technical-route-blueprint-planner。
请根据以下研究内容和实验方案，输出技术路线图的文本骨架，
用箭头和泳道结构表达，例如体外实验、体内验证、数据分析、机制建模。

[在此处粘贴研究内容、研究方案、实验方法]
```

---

## 模板 9：400 字国自然摘要

```
请使用 nsfc-abstract-compressor。
请将以下完整申请书内容压缩为 400 字以内项目摘要，
结构为：背景、问题空白、前期基础、科学假说、拟开展内容、科学意义。
剔除参考文献标记。

[在此处粘贴完整申请书全文或关键信息]
```

---

## 模板 10：术语一致性与连贯性校对

```
请使用 terminology-coherence-editor。
请审查以下申请书章节，统一术语，删除 AI 套话，
修复章节间逻辑衔接，但不得修改科学事实。

[在此处粘贴申请书章节草稿]
```

---

## 模板 11：函评专家模拟质询

```
请使用 nsfc-reviewer-simulation-auditor。
请模拟严格国自然函评专家，审查以下申请书草稿中的
关键科学问题、创新性、实验可行性和前期基础，
输出 3 条尖锐且专业的质询意见和修改建议。

[在此处粘贴申请书草稿、前期基础、研究方案、创新点]
```

---

## 快速组合示例

### 国自然全流程

```
第一步：请使用 key-scientific-question-extractor
        从以下初步设想中提炼关键科学问题：[粘贴]

第二步：请使用 objective-content-alignment-planner
        将科学问题拆解为目标和内容：[粘贴]

第三步：请使用 proposal-rationale-gap-locator
        构建立项依据大纲：[粘贴文献清单]

第四步：请使用 nsfc-abstract-compressor
        压缩 400 字摘要：[粘贴全文]

第五步：请使用 nsfc-reviewer-simulation-auditor
        模拟函评专家：[粘贴申请书草稿]
```

### 立项依据 + 创新点组合

```
第一步：请使用 critical-literature-review-pipeline
        完成文献综述：[粘贴文献]

第二步：请使用 proposal-innovation-extractor
        提炼创新点：[粘贴申请书]

第三步：请使用 surface-innovation-auditor
        驳回表面创新

第四步：请使用 three-point-innovation-packager
        封装为三点式
```
