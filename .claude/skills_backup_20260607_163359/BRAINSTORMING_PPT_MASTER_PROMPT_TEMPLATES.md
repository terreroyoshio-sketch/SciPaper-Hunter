# Brainstorming & PPT Master — 提示词模板

---

## 模板 1：方案发散

```
请使用 brainstorming。我的任务是【填写任务】。
请先生成 3 套可执行方案，每套包含目标、适用场景、
优点、风险、所需材料、执行步骤和验收标准。
最后推荐最稳妥的一套。
```

## 模板 2：论文转 PPT 前期策划

```
请使用 brainstorming、markitdown 和 nature-paper2ppt。
请先读取论文材料，判断适合哪种汇报叙事结构，
然后给出 3 套 PPT 结构方案。不要直接生成 PPT，先让我选择方案。
```

## 模板 3：生成可编辑 PPTX

```
请使用 ppt-master。请基于以下材料生成一份真正可编辑的 PPTX。
要求使用真实 PowerPoint shapes，不要把整页做成截图。
输出 pptx 文件、资产清单、字体和配色说明、每页备注和质量检查结果。
```

## 模板 4：项目申报书展示 PPT

```
请使用 brainstorming、nsfc-proposal-architecture-pipeline、
objective-innovation-auditor-pipeline、nature-figure 和 ppt-master。
先提炼关键科学问题、创新点和技术路线，再生成正式展示 PPTX。
```

## 模板 5：答辩 PPT 优化

```
请使用 ppt-master、nature-figure 和 reviewer-red-team-auditor。
检查现有 PPT 的每页结论、图文匹配、逻辑连贯性和字数，
然后输出修改后的可编辑 PPTX 和逐页修改记录。
```

## 模板 6：组会汇报 PPT

```
请使用 nature-paper2ppt 和 ppt-master。
将以下论文整理成 10-16 页中文组会汇报 PPT。
用 nature-paper2ppt 负责学术叙事，用 ppt-master 生成可编辑 pptx。
```
