# 批判性文献综述 — 与已有 Skills 组合工作流

---

## A. 写 SCI 综述型论文时

```
1. using-superpowers
   先明确综述主题、边界、目标期刊、字数、引文格式和验收标准。

2. brainstorming
   生成 2 到 3 套综述主题框架。

3. keyword-literature-download
   检索并下载相关论文，生成题录库。

4. markitdown
   将 PDF、Word 或网页转成 Markdown。

5. literature-boundary-lock
   锁定人工核实文献数据边界。

6. critical-literature-review-pipeline
   执行主题聚类、争议梳理、方法局限、漏斗排序、研究空白界定。

7. citation-format-syntax-auditor
   最终校正文献引用句法和格式。
```

---

## B. 写国自然国内外研究现状时

```
1. keyword-literature-download
   分别检索国内和国际文献。

2. literature-boundary-lock
   锁定国内外文献数据边界。

3. domestic-international-paradigm-comparator
   客观对比国内外研究范式。

4. methodological-limitation-synthesizer
   提取方法论共性不足。

5. research-gap-definer
   生成项目拟解决的研究空白。

6. objectivity-calibration-auditor
   防止夸大前人不足。
```

---

## C. 写学位论文综述部分时

```
1. markitdown
   整理导师给的论文、学位论文、笔记。

2. literature-theme-clustering
   按主题聚类，而不是按时间罗列。

3. funnel-logic-sorter
   按宏观到微观组织章节。

4. paragraph-logic-bridge
   补充段落衔接。

5. citation-format-syntax-auditor
   修正引文句法。
```

---

## D. 写项目申报书研究背景时

```
1. using-superpowers
   确认申报要求和评审标准。

2. keyword-literature-download
   检索项目相关文献。

3. methodological-limitation-synthesizer
   提出现有方法不足。

4. research-gap-definer
   生成项目必要性和研究空白。

5. objectivity-calibration-auditor
   防止夸大行业痛点和前人不足。
```

## E. 与创新点审计流水线结合

```
1. critical-literature-review-pipeline
   先证明研究空白。

2. objective-innovation-auditor-pipeline
   再审计创新点是否成立。

3. reviewer-red-team-auditor
   最后模拟审稿人质疑。
```

---

## F. 与文献综述闭环流水线结合

**注意**：`critical-literature-review-pipeline`（本组）与 `literature-review-closed-loop-pipeline`（此前安装）的区别：

| 维度 | critical-literature-review-pipeline | literature-review-closed-loop-pipeline |
|------|------------------------------------|--------------------------------------|
| 侧重点 | 批判性 + 国内外范式对比 + 客观性校准 | 主题综合 + 理论演进 + 概念框架 |
| 适用范围 | SCI 综述、国自然、学位论文 | 一般文献综述、项目申报 |
| 特殊步骤 | 国内外范式对比、客观性校准 | 理论演进映射、概念框架构建 |

可根据需要选用或组合：

```
第一步：使用 critical-literature-review-pipeline
        完成文献边界锁定、主题聚类、争议梳理、研究空白界定。

第二步：使用 literature-review-closed-loop-pipeline 中的
        theoretical-evolution-mapper 补充理论演进分析。

第三步：使用 literature-review-closed-loop-pipeline 中的
        conceptual-framework-builder 构建概念框架。
```
