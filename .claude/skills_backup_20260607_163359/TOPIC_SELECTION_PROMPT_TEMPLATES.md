# 论文选题方法论 — 提示词模板

---

## 模板 1：完整论文选题

```
请使用 paper-topic-selection-methodology。
我的学科是【填写】，研究层次是【本科/硕士/博士】，
截止时间是【填写】，可用资源是【填写】，
方法基础是【填写】，导师偏好是【填写】。
请先联网建立不少于 20 篇真实文献的最小文献池，
然后生成 8 到 12 个候选题，进行四维评分，
收敛 TOP3，做数据可得性 MVP 预审，
最后输出一页式定题卡。
```

---

## 模板 2：题目太大收缩

```
请使用 paper-topic-selection-methodology。
以下是我的初始题目。请从研究对象、时间范围、地区边界、
核心变量、方法路径五个维度帮我收缩，
并说明每个收缩版本的可行性和风险。
```

---

## 模板 3：TOP3 选题比较

```
请使用 paper-topic-selection-methodology。
请将以下候选题按价值、创新、可行、匹配四维评分，
选出 TOP3，并说明淘汰理由、保留理由和导师沟通话术。
```

---

## 模板 4：数据可得性预审

```
请使用 paper-topic-selection-methodology。
请对以下候选题做数据可得性预审，按 A/B/C/D 分级，
列出数据路径、获取周期、授权风险和 Plan B。
无可用数据的题目请标记为不建议。
```

---

## 模板 5：一页式定题卡

```
请使用 paper-topic-selection-methodology。
请为以下题目输出一页式定题卡，包括题目、背景、研究问题、
数据来源、方法路径、预期贡献、风险 Plan B、
48 小时行动清单和 2 周行动清单。
```

---

## 模板 6：导师沟通版

```
请使用 paper-topic-selection-methodology 和 reviewer-red-team-auditor。
请把以下 TOP3 选题整理为导师沟通材料，
并模拟导师可能提出的 5 个尖锐问题。
```

---

## 模板 7：开题报告准备

```
请使用 paper-topic-selection-methodology、critical-literature-review-pipeline
和 nsfc-proposal-architecture-pipeline。
请把已选题目扩展为开题报告结构，包括研究背景、研究现状、
研究空白、研究问题、研究方法、技术路线和进度安排。
```
