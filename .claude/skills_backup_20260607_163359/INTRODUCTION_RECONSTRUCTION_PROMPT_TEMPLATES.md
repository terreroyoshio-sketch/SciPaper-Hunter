# 引言重构 — 提示词模板

## 模板 1：完整引言重构
```
请使用 introduction-reconstruction-pipeline。请按宏观背景→文献聚类→局限→空白→目标→假设/RQ→方法→贡献→概念边界→路线图的逻辑重构以下引言。不得编造文献、数据或研究空白。
```

## 模板 2：宏观背景压缩
```
请使用 macro-background-compressor。从以下背景草稿中提取与研究主题直接相关的宏观语境。未经证实的统计请标注需补证。
```

## 模板 3：文献主题聚类
```
请使用 literature-theme-clusterer。将以下已核实文献按主题、机制、理论或方法论聚类。不得虚构引用。
```

## 模板 4：前人局限性评估
```
请使用 prior-study-limitation-auditor。提取前人研究在理论、方法、样本上的局限。要求客观，不得贬低前人。
```

## 模板 5：研究空白阐述
```
请使用 specific-research-gap-articulator。将以下局限性综合为一个具体研究空白声明。
```

## 模板 6：研究目标声明
```
请使用 research-objective-statement-writer。基于以下研究空白和核心发现，写出1-3个具体研究目标。
```

## 模板 7：假设格式化
```
请使用 hypothesis-rq-formatter。根据以下变量整理为H1/H2或RQ1/RQ2。不得合成未定义的变量关系。
```

## 模板 8：方法合理性
```
请使用 methodological-rationale-auditor。解释所选方法为什么适合解决该研究空白。
```

## 模板 9：贡献提炼
```
请使用 theoretical-empirical-contribution-extractor。从以下摘要、结果和结论中提炼理论、实证和方法贡献。不得使用自我赞美表达。
```

## 模板 10：概念边界定义
```
请使用 concept-boundary-definer。生成核心概念的操作性定义和研究边界说明。
```

## 模板 11：结构路线图
```
请使用 manuscript-structure-roadmap-writer。根据以下章节标题生成引言结尾的路线图段落。
```
