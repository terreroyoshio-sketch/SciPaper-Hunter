# 科研绘图提示词指南 — Scientific Image Prompting Guide

> 本指南保存了科研绘图提示词的核心结构、通用母版、8 种图类型专用规则、
> 输出格式、科研严谨性边界以及与已有 skills 的组合方法。
>
> 以后我要求你写科研绘图提示词时，将自动采用本框架。

---

## 一、核心结构

科研绘图提示词 = 图类型 + 主体对象 + 机制链条 + 构图方式 + 风格配色 + 负面限制

| 要素 | 说明 | 必须包含 |
|------|------|---------|
| 图类型 | 图形摘要 / 机制图 / 流程图 / 封面图 / 技术路线图 | ✅ |
| 主体对象 | 材料、细胞、分子、器件、实验对象 | ✅ |
| 机制链条 | 谁→影响谁→导致什么结果（3-6 步） | ✅ |
| 构图方式 | 从左到右 / 中心聚焦 / 分层 / 多面板 | ✅ |
| 风格配色 | 简洁专业、主色+强调色、背景要求 | ✅ |
| 负面限制 | 禁止元素堆积、复杂背景、大段文字、过度海报化 | ✅ |

## 二、通用母版

### 中文母版

```
请生成一张用于论文的【图的类型】，主题是【研究主题】。
图中展示【主体对象】、【关键过程 1】、【关键过程 2】以及【最终结果】。
请采用【构图方式】布局，并通过箭头、局部放大视图或分层结构来强化机制表达。
整体风格要求简洁、专业、适合论文发表，呈现高质量科研示意图风格，
具有清晰的结构层级和良好的可读性。
请使用【背景要求】，以【主色】为主色，并用【强调色】突出关键事件。
请避免复杂背景、大段文字、元素堆积、无关装饰和过度海报化效果。
```

### 英文母版

```
Create a publication-ready 【type of figure】 about 【research topic】.
Show 【main objects】, 【key process 1】, 【key process 2】, and 【final outcome】.
Use a 【layout type】 composition, and strengthen the mechanistic presentation
with arrows, zoom-in views, or layered structures.
Use a clean, professional, high-quality scientific illustration style
with clear visual hierarchy and strong readability.
Use 【background requirement】, with 【primary color】 as the dominant palette
and 【accent color】 for highlighting key events.
Avoid complicated backgrounds, long text blocks, cluttered elements,
unnecessary decoration, and an overly poster-like appearance.
```

## 三、图形摘要模板

**适用场景**: 药物递送、材料作用路径、项目核心机制、论文主结论概览

**写法规则**:
- 按"输入/给药 → 富集/识别 → 摄取/作用 → 响应/释放 → 机制变化 → 最终结果"组织
- 优先从左到右布局，箭头表示顺序
- 用 1-2 个局部放大视图展示关键机制
- 不要只画主体，要画完整路径

**默认句式**:
```
请采用从左到右的图形摘要布局，依次展示【阶段 1】、【阶段 2】、
【阶段 3】、【阶段 4】和【最终结果】。
```

## 四、机制图模板

**适用场景**: 免疫微环境、细胞死亡、信号通路、抗菌机制、材料催化机制

**写法规则**:
- 重点不是步骤感，而是关系感
- 必须写清楚谁影响谁（激活、抑制、增强、削弱、损伤）
- 可采用中心场景 + 周围局部放大视图
- 用箭头、抑制符号（⊥）、激活符号表达关系

**默认句式**:
```
请采用中心聚焦式机制图布局，以【核心场景】为主画面，
在周围加入局部放大视图，用于展示【对象 A】与【对象 B】之间
的激活、抑制或损伤关系。
```

## 五、实验流程图模板

**适用场景**: 方法概览、课题技术路线、组会汇报、项目申报书流程图

**写法规则**:
- 阶段必须清楚，顺序必须明确
- 每一步用独立小场景或图标化元素表示
- 用箭头连接阶段，避免大段文字

**默认句式**:
```
请从左到右依次展示【步骤 1】、【步骤 2】、【步骤 3】、【步骤 4】和【步骤 5】。
每个步骤使用独立的小场景或图标化科研元素表示，并用箭头连接。
```

## 六、材料/能源/催化机制图模板

**适用场景**: 异质结、催化反应、电荷迁移、电化学加工、界面反应、光催化、储能材料

**写法规则**:
- 不要只描述材料外观
- 必须写清楚界面在哪里
- 必须写清楚电子、空穴、离子或能量怎么迁移
- 必须写清楚反应路径和最终产物
- 采用分层布局

**默认句式**:
```
请采用分层布局，顶部展示【输入条件】，中部展示【材料结构或界面】
以及【电子/离子/能量迁移路径】，底部展示【活性物种/反应产物/功能结果】。
请通过局部放大视图突出界面细节。
```

## 七、期刊封面图模板

**适用场景**: 答辩封面、投稿封面、项目宣传主视觉

**写法规则**:
- 先确定绝对主视觉，其他元素围绕主视觉服务
- 要有空间感和冲击力，但不能失去科学合理性
- 不要过度卡通或幻想化

**默认句式**:
```
请采用中心主体构图，以【核心对象】作为视觉中心，周围围绕【辅助元素 1】、
【辅助元素 2】和【作用效果】形成具有空间层次的高冲击画面。
整体应具有国际期刊封面感，但保持科学合理性。
```

## 八、细胞死亡机制图模板

**适用场景**: 凋亡、焦亡、铁死亡、坏死性凋亡、ROS 诱导治疗

**写法规则**:
- 必须明确是哪一种死亡方式
- 必须写清楚触发因素、分子事件、最终形态学/功能结果
- 不要只写"诱导细胞死亡"

**默认句式**:
```
图中展示【治疗材料或刺激因素】进入【细胞类型】后，诱导【分子事件 1】、
【分子事件 2】、【分子事件 3】，最终导致【具体细胞死亡方式】。
```

## 九、亚细胞定位机制图模板

**适用场景**: 线粒体靶向、溶酶体响应、细胞核定位、内质网应激、细胞膜损伤

**写法规则**:
- 必须写清楚怎么进入细胞
- 必须写清楚定位到哪个细胞器
- 必须写清楚在该细胞器中发生什么
- 必须写清楚最终细胞命运

**默认句式**:
```
图中展示【药物或材料】进入【细胞】后，选择性定位到【细胞器】，
进一步诱导【功能变化 1】、【功能变化 2】和【功能变化 3】，
最终导致【细胞结果】。
```

## 十、核酸药物递送图模板

**适用场景**: siRNA、mRNA、DNA、CRISPR、基因编辑递送

**写法规则**:
- 强调递送路径、细胞内转运
- 必须写清楚内吞、内体逃逸、释放位置和最终调控结果
- 不要只写"递送到靶点"

**默认句式**:
```
图中展示【纳米载体】包裹【核酸药物】，经【递送路径】富集于【靶组织】，
被细胞摄取后进入【内体/溶酶体】，随后发生【内体逃逸】，
并将核酸释放至【细胞质/细胞核】，最终实现【基因沉默/蛋白表达/基因编辑】。
```

## 十一、抗菌机制图模板

**适用场景**: 抗菌材料、纳米酶、光热抗菌、光动力抗菌、生物膜清除

**写法规则**:
- 必须把病原体、作用方式和杀菌结果同框呈现
- 不能只画材料和细菌
- 必须写清楚膜损伤、ROS、生物膜破坏、热效应等具体机制

**默认句式**:
```
图中展示【抗菌材料或平台】与【细菌或生物膜】接触后，
通过【膜破坏】、【ROS 生成】、【生物膜抑制】或【局部热效应】实现杀菌。
请用局部放大视图展示材料与细菌膜、胞内成分或生物膜基质之间的相互作用。
```

## 十二、负面提示词模板

```
请避免：
- 元素堆积和画面过于拥挤
- 复杂或渐变色背景
- 大段英文或中文文字
- 过度卡通化或幻想化风格
- 海报式排版
- 错误的箭头方向和逻辑关系
- 伪科学结构（如不存在的分子结构或通路）
- 无关装饰元素
- 过度鲜艳或不协调的配色
```

## 十三、输出固定格式

以后我为你生成科研绘图提示词时，按以下 6 部分输出：

### 1. 图类型判断
说明这张图更适合做什么类型（图形摘要/机制图/流程图/封面图/技术路线图）。

### 2. 画面逻辑
用 3-6 个步骤说明图中要表达的机制链条或关系网络。

### 3. 中文提示词
可直接复制到 GPT-Image-2 或其他图像模型中的中文提示词。

### 4. English Prompt
英文版提示词，可直接用于 GPT-4o Image Generation 或 DALL-E / Midjourney。

### 5. 负面提示词
列出不要出现的内容。

### 6. 后期修正建议
生成后人工核查重点：箭头方向、术语拼写、细胞器位置、材料结构、机制顺序、颜色含义、图注一致性。

## 十四、科研严谨性边界（硬约束）

1. 不得把未验证机制画成已证实机制。
2. 不得添加论文中没有的关键通路、分子、细胞器或实验结果。
3. 不得把推测性机制画成确定因果。
4. 不得把图画得比数据更强。
5. 不得伪造统计图、实验结果、谱图、显微图或真实数据图。
6. 图形摘要和机制示意图可以是概念性表达，但必须与用户提供的研究内容一致。
7. 真实数据图（统计图、回归图、遥感图、地图）优先使用 matplotlib、seaborn、plotly、scientific-visualization、geopandas、geomaster 或 nature-figure，而不是图像生成模型。
8. 投稿级图件应结合 nature-figure、scientific-visualization 和 journal-formatting-pipeline 做二次审计。
9. 所有文字标签和术语生成后必须人工核查（图像模型容易拼错文字）。
10. 准确分子结构、晶体结构、仪器结构或空间比例应优先用专业绘图软件或代码生成，再用 AI 辅助美化。
