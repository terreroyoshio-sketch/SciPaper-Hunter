# Cover Letter — 与已有 Skills 组合工作流

---

## A. 顶刊 Cover Letter 全流程

```
1. using-superpowers
   明确目标期刊、稿件类型、长度要求、投稿系统要求和验收标准。

2. markitdown
   将 Word / PDF 稿件转成可处理文本。

3. empirical-result-extraction-auditor
   提取真实研究发现，防止贡献外推。

4. objective-innovation-auditor-pipeline
   审计贡献点是否成立，删除表面创新。

5. cover-letter-pipeline
   生成正式投稿信。

6. academic-tone-standardizer
   删除奉承和 AI 痕迹。

7. grammar-correction-auditor
   最终语法校对。
```

---

## B. Nature 风格投稿信

```
1. nature-polishing
   润色英文表达。

2. nature-citation
   如需补充引用支持，只使用可核查文献。

3. nature-data
   补齐数据可用性声明。

4. cover-letter-assembly-length-auditor
   组装并控制长度。
```

---

## C. 期刊匹配说明

```
1. journal-scope-alignment-writer
   基于用户提供的期刊 scope 进行匹配说明。

2. research-significance-compressor
   压缩研究意义。

3. empirical-contribution-extractor
   提取贡献。

4. academic-tone-standardizer
   删除奉承语。
```

---

## D. 投稿合规声明

```
1. originality-status-statement-generator
   生成原创与未一稿多投声明。

2. ethics-compliance-statement-formatter
   生成利益冲突、资金、伦理声明。

3. reviewer-data-formatter
   整理推荐或回避审稿人。
```

---

## E. 论文申报书与投稿材料统一整理

```
1. word-document-processor
   整理投稿材料和 Cover Letter docx。

2. docs
   生成投稿清单。

3. summarize
   提炼审稿关注点。

4. cover-letter-pipeline
   生成投稿信。
```
