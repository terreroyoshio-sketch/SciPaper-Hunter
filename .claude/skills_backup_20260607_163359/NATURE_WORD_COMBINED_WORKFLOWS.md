# Nature Figure + Word Document — 与已有 Skills 组合工作流

---

## A. 论文图件工作流

```
1. using-superpowers
   明确图件目标、期刊要求、数据来源和验收标准。

2. markitdown
   解析论文草稿、结果和图注。

3. empirical-result-extraction-auditor
   提取真实结果，防止图中结论超出数据。

4. nature-figure
   生成 figure contract、绘图代码、图注和导出设置。

5. reviewer-red-team-auditor
   从审稿人角度检查图件逻辑。

6. word-document-processor
   将图件和图注嵌入 Word 论文稿。
```

---

## B. 项目申报书 Word 成稿工作流

```
1. using-superpowers
   确认申报模板、页数、格式和验收标准。

2. nsfc-proposal-architecture-pipeline
   检查申请书逻辑结构。

3. objective-innovation-auditor-pipeline
   审计创新点。

4. terminology-coherence-editor
   统一术语。

5. word-document-processor
   按模板生成或修改 docx。
```

---

## C. SCI 综述图文工作流

```
1. keyword-literature-download
   构建文献库。

2. literature-boundary-lock
   锁定文献边界。

3. critical-literature-review-pipeline
   生成批判性综述结构。

4. conceptual-framework-builder 或 research-gap-definer
   提炼概念框架和研究空白。

5. nature-figure
   绘制理论框架图、机制图或证据矩阵图。

6. word-document-processor
   生成 Word 版综述初稿。
```

---

## D. 翻译与期刊格式整理工作流

```
1. markitdown
   解析 PDF 或 Word。

2. academic-vocabulary-auditor
   统一术语。

3. syntax-clarity-auditor
   清理长句和机翻腔。

4. word-document-processor
   按目标期刊模板排版。

5. grammar-correction-auditor
   最终校对。
```

---

## E. PPT 与答辩材料工作流

```
1. brainstorming
   生成展示结构。

2. technical-route-blueprint-planner
   生成技术路线图文本。

3. nature-figure
   生成高质量科研图件。

4. word-document-processor
   整理讲稿、申报书附件或答辩说明文档。
```

---

## F. 完整论文写作全流程

```
1. using-superpowers                        → 明确任务目标和边界
2. keyword-literature-download              → 检索文献
3. critical-literature-review-pipeline      → 生成综述
4. objective-innovation-auditor-pipeline    → 审计创新点
5. nature-figure                            → 绘制图件
6. nsfc-proposal-architecture-pipeline      → 基金架构审计（如果适用）
7. terminology-coherence-editor             → 术语一致性
8. word-document-processor                  → Word 成稿
9. citation-format-syntax-auditor           → 引文校对
10. verification-before-completion          → 最终验收
```
