# 文献综述闭环写作 — 提示词模板

以下模板可直接复制并在 Claude Code 中使用。

---

## 模板 1：文献边界锁定

```
请使用 literature-boundary-lock。以下是我已经核实的文献题录和摘要。
你只能基于这些文本进行综合，不得虚构任何作者、年份、DOI、期刊或结论。
如果某项信息缺失，请标注"在提供的文本中未找到相关信息"。

[在此处粘贴已核实的文献题录和摘要]
```

---

## 模板 2：主题聚类综述

```
请使用 literature-theme-synthesis。请将以下文献按 3 到 4 个概念性主题分组，
并生成主题驱动的综述段落。禁止采用"作者 A 说、作者 B 说"的流水账结构。

[在此处粘贴文献摘要]
```

---

## 模板 3：理论演进

```
请使用 theoretical-evolution-mapper。请基于以下按年份排序的文献，
写出该领域理论或技术路线的演进段落。不得引入未提供文献之外的历史背景。

[在此处粘贴按时间排序的文献摘要]
```

---

## 模板 4：学术争议

```
请使用 academic-debate-mapper。请从以下文献中识别相互矛盾的结果、
竞争性理论或方法分歧，并客观写成一个学术争论段落。

[在此处粘贴文献摘要和结果摘录]
```

---

## 模板 5：方法论局限

```
请使用 methodological-limitation-auditor。请综合以下文献的方法和局限性，
写出该领域目前存在的共性方法缺陷。不得夸大前人不足。

[在此处粘贴文献方法部分和局限性部分]
```

---

## 模板 6：概念框架

```
请使用 conceptual-framework-builder。请从以下文献中提取自变量、因变量、
中介变量和调节变量，并构建一个有文献支撑的概念框架。

[在此处粘贴文献摘要、变量描述和结果摘录]
```

---

## 模板 7：漏斗式综述

```
请使用 funnel-logic-organizer。请将以下主题段落按
"宏观背景—主流方法—细分问题—研究空白"的漏斗结构重新排列，
并输出结构化综述文本。

[在此处粘贴已综合的主题段落]
```

---

## 模板 8：段落桥接

```
请使用 citation-bridge-writer。请为段落 A 和段落 B 写一个逻辑桥接句，
重点体现二者之间的对比、递进、转化或范围收缩关系。
不要使用"接下来""此外"等普通过渡词。

段落 A：
[在此处粘贴段落A]

段落 B：
[在此处粘贴段落B]
```

---

## 模板 9：研究缺口

```
请使用 research-gap-synthesizer。请根据以下文献综述、争议和方法局限，
写出一个高信息密度研究缺口段落，必须包含"空白""尚未解决"或"关键瓶颈"等表达。

[在此处粘贴漏斗式文献综述 + 学术争论段落 + 方法论缺陷段落 + 项目研究目标]
```

---

## 模板 10：引文句法校对

```
请使用 citation-syntax-auditor。请优化以下文献综述中的引文句法。
不得更改任何作者姓名、年份或引用来源，只能调整句子结构和引用位置。

引文格式要求：[APA / GB/T 7714 / 数字编号制]

[在此处粘贴文献综述草稿]
```

---

## 模板 11：完整闭环综述流水线

```
请使用 literature-review-closed-loop-pipeline。
以下是我人工核实后的 20 到 30 篇核心文献题录与摘要。
请严格锁定数据边界，依次完成：
1. 主题聚类
2. 理论演进
3. 学术争议
4. 方法局限
5. 概念框架
6. 漏斗结构
7. 研究缺口
8. 引文句法校对

不得虚构任何引文信息。

研究主题：[在此处填写]
目标期刊/用途：[在此处填写]
引文格式要求：[在此处填写]
拟研究目标：[在此处填写]

[在此处粘贴已核实的文献题录和摘要]
```

---

## 快速组合示例

### 完整文献综述（使用流水线）

```
请使用 literature-review-closed-loop-pipeline。

研究主题：钛合金高速切削加工表面完整性
目标期刊：Journal of Materials Processing Technology
引文格式要求：APA
拟研究目标：建立切削参数-表面完整性-疲劳寿命的关联模型

以下是我人工核实的 25 篇核心文献题录与摘要：

[粘贴文献清单...]
```

### 仅做主题综合 + 研究缺口

```
第一步：
请使用 literature-theme-synthesis。将以下文献按主题聚类...

第二步：
请使用 research-gap-synthesizer。根据以上综合结果，写出研究缺口段落...
```
