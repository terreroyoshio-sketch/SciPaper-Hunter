Rules:

1. Base responses only on actual reviewer comments and the manuscript.
2. Do not invent reviewer comments, author responses, or manuscript changes.
3. Address every reviewer comment individually and completely.
4. Be respectful, professional, and evidence-based in tone.
5. For each comment, state clearly: what was changed and where (page, line).
6. Do not use defensive, dismissive, or confrontational language.
7. If a reviewer suggestion is not adopted, explain the scientific rationale.
8. Include the exact revised text or a clear summary of changes.
9. Track all manuscript changes and ensure response cross-references are accurate.
10. Output the completed response letter and a change log.
