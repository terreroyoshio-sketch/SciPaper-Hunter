# PaperBanana Output Auditor

## 概述

对 PaperBanana MCP 生成的结果进行系统质量检查。审计维度沿用 PaperBanana 论文的评估框架：Faithfulness（忠实度）、Conciseness（简洁性）、Readability（可读性）、Aesthetics（美学），并增加学术规范性维度。

## 审计流程

```
PaperBanana 输出
    ↓
维度 1: 忠实度检查（Faithfulness）
维度 2: 简洁性检查（Conciseness）
维度 3: 可读性检查（Readability）
维度 4: 美学检查（Aesthetics）
维度 5: 学术规范检查（Academic Standards）
    ↓
审计报告
    ↓
修复建议
    ↓
→ 通过 → 嵌入文档/PPT
→ 不通过 → 返回 continue_run 继续迭代
```

## 审计维度

### 维度 1: 忠实度 (Faithfulness) — 权重最高

检查生成图是否准确反映了输入文本的科学内容。

| 检查项 | 通过标准 | 修复方法 |
|--------|---------|---------|
| 组件存在性 | 所有在 method_text 中描述的关键组件都在图中出现 | 通过 continue_run 补充缺失组件 |
| 连接正确性 | 箭头方向/连接关系与描述一致 | 修正箭头方向或连接关系 |
| 标注准确性 | 图中文字/数值标注与描述一致 | 修正图中标注 |
| 流程顺序 | 各步骤按正确的逻辑顺序排列 | 调整顺序 |
| 未添加虚构内容 | 图中没有 method_text 中未描述的元素 | 移除多余元素 |

**评分标准：** 1-10 分，≥7 分通过

### 维度 2: 简洁性 (Conciseness) — 辅助维度

检查图是否避免了不必要的细节和视觉噪音。

| 检查项 | 通过标准 | 修复方法 |
|--------|---------|---------|
| 元素数量 | 每个面板包含必要元素，无冗余装饰 | 删除无关装饰元素 |
| 文字精炼 | 图中文字简洁，无冗余描述 | 简化文字说明 |
| 颜色使用 | 颜色数量合理，每色有功能含义 | 减少装饰性颜色使用 |
| 线条密度 | 线条不交叉不密集 | 简化连线 |

**评分标准：** 1-10 分，≥6 分通过

### 维度 3: 可读性 (Readability) — 核心维度

检查图的信息呈现是否清晰易读。

| 检查项 | 通过标准 | 修复方法 |
|--------|---------|---------|
| 字号 | ≥ 6pt（印刷）/ ≥ 14pt（PPT） | 增大字号 |
| 对比度 | 文字与背景有足够对比 | 调整颜色对比 |
| 重叠 | 无文字重叠、箭头重叠 | 重新布局 |
| 分组 | 相关元素在视觉上靠近 | 调整空间分组 |
| 阅读顺序 | 整体符合左上→右下阅读习惯 | 重新排列面板 |

**评分标准：** 1-10 分，≥7 分通过

### 维度 4: 美学 (Aesthetics) — 加分维度

检查图的视觉质量和整体观感。

| 检查项 | 通过标准 | 修复方法 |
|--------|---------|---------|
| 配色和谐 | 色彩搭配专业、协调 | 使用预设学术色板 |
| 对齐 | 各面板对齐整齐 | 对齐面板 |
| 间距 | 元素间距均匀 | 统一间距 |
| 字体一致 | 全图字体风格统一 | 统一字体 |
| 比例 | 各元素比例协调 | 调整尺寸比例 |

**评分标准：** 1-10 分，≥6 分通过

### 维度 5: 学术规范 (Academic Standards) — 硬性维度

检查图是否符合目标期刊/场景的格式要求。

| 检查项 | 通过标准 | 修复方法 |
|--------|---------|---------|
| 面板标号 | 多面板图有 (a)(b)(c) 标号 | 添加面板标号 |
| 图例 | 有必要的图例说明 | 添加图例 |
| 缩写 | 非标准缩写有解释 | 添加缩写说明 |
| 比例尺 | 必要时有比例尺/单位 | 添加单位说明 |
| 期刊格式 | 符合目标期刊的 Figure Guidelines | 按指南调整 |

**评分标准：** 1-10 分，必须 10 分通过（硬性要求）

## 审计报告模板

```markdown
# PaperBanana 输出审计报告

## 基本信息
- 图件类型: [Methodology Diagram / Graphical Abstract / ...]
- 目标场景: [Nature / 中文核心 / 国自然 / PPT / ...]
- 生成工具: [generate_diagram / generate_plot / continue_run]

## 各维度评分
| 维度 | 分数 | 通过？ | 说明 |
|------|------|--------|------|
| 忠实度 | /10 | ✅/❌ | |
| 简洁性 | /10 | ✅/❌ | |
| 可读性 | /10 | ✅/❌ | |
| 美学 | /10 | ✅/❌ | |
| 学术规范 | /10 | ✅/❌ | |

## 关键问题
1. [问题 1 + 对应建议]

3. [问题 3 + 对应建议]

- 如需要继续迭代 → 使用 continue_run 并附以下反馈：
  [具体反馈文本]

- ✅ 通过 / ❌ 需要修改 / ❌ 建议重生成
```

## 注意事项

1. **忠实度优先** — 学术图件的生命线是科学准确性，即使不美观也要优先保证忠实
2. **不要过度追求美学** — 简洁清晰的示意图优于花哨的信息图
3. **学术规范不可妥协** — 缺少面板标号、图例等硬伤不能接受
4. **迭代上限** — 如果 3 次 continue_run 后仍不通过，建议重新生成或改用其他工具
5. **若不通过** — 输出具体、可执行的修改意见，而非笼统的"不够好"

## 与其它工具的关系

| 如果本 audit 不通过... | 替代方案 |
|----------------------|---------|
| 忠实度不足 | 重新写 brief，补充缺失细节 → 调用 generate_diagram |
| 可读性差 | 改用 nature-figure（代码生成矢量图） |
| 美学不满足 | 改用 scientific-schematics（Gemini 质量审核） |
| 需要纯矢量图 | 改用 nature-figure（Python matplotlib → SVG/PDF） |
