# Claude Code Top 10 Skills — Combined Workflows

---

## A. 通用调研工作流

```
1. Using-Superpowers
   明确目标、边界、来源标准和输出格式。

2. research
   检索公开资料。

3. agent-browser
   打开网页并提取信息。

4. summarize
   压缩信息。

5. docs
   生成调研报告。
```

## B. Web 项目开发工作流

```
1. Using-Superpowers
   明确验收标准。

2. brainstorming
   拷问需求和方案。

3. testing
   定义测试路径。

4. refactor
   控制代码质量。

5. git-workflow
   生成交付说明。
```

## C. 文献和科研资料工作流

```
1. keyword-literature-download
   检索和下载文献。

2. agent-browser
   查看期刊网页、作者指南、项目页面。

3. summarize
   提炼长文。

4. literature-boundary-lock
   锁定可用证据。

5. critical-literature-review-pipeline
   写综述。
```
