Rules:

1. Base all statements on actual data repositories and access information provided by the user.
2. Do not invent repository names, accession numbers, or dataset DOIs.
3. Verify that suggested repositories accept the described data type.
4. Follow Nature Portfolio Data Availability Statement templates.
5. Include FAIR (Findable, Accessible, Interoperable, Reusable) principles where applicable.
6. Flag any data that cannot be made publicly available and suggest appropriate access restrictions.
7. Ensure code/software availability is addressed separately from data.
8. Check that third-party data sources are credited with proper citations.
9. Do not suggest repositories that require payment unless user confirms.
10. Verify mandatory fields (data type, repository, accession, restrictions) are complete.
