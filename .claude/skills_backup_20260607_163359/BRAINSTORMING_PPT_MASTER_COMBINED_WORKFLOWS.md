# Brainstorming & PPT Master — 组合工作流

---

## A. PPT 从 0 到 1

```
1. using-superpowers    → 明确用途、观众、页数、风格
2. brainstorming        → 3 套叙事结构方案
3. markitdown           → 解析源材料
4. summarize            → 提炼核心内容
5. ppt-master           → 生成可编辑 PPTX
6. reviewer-red-team-auditor → 检查逻辑漏洞
```

## B. 学术论文转组会 PPT

```
1. markitdown           → 解析论文
2. nature-paper2ppt     → 判断论文类型 + 学术叙事
3. nature-figure        → 优化图件
4. ppt-master           → 生成可编辑 PPTX
5. word-document-processor → 讲稿说明
```

## C. 项目申报书 PPT

```
1. nsfc-proposal-architecture-pipeline → 提炼逻辑
2. objective-innovation-auditor-pipeline → 审计创新点
3. nature-figure        → 技术路线图/机制图
4. brainstorming        → 比较展示结构
5. ppt-master           → 生成展示 PPT
```

## D. 竞赛或路演 PPT

```
1. brainstorming        → 路演叙事
2. objective-innovation-auditor-pipeline → 审计亮点
3. nature-figure        → 高质量图件
4. ppt-master           → 可编辑 PPTX
5. reviewer-red-team-auditor → 模拟评委质疑
```
