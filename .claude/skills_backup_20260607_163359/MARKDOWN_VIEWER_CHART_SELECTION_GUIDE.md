# Markdown Viewer Chart Selection Guide

## 1. Mermaid

**适合：**
- 简单流程图
- 序列图
- 状态机
- 甘特图
- ER 图
- 思维导图
- 简单架构流程
- 文档中需要 GitHub 原生渲染的图

**不适合：**
- 复杂企业架构
- 大规模依赖图
- 高度定制数据可视化
- 精美信息卡片

## 2. Vega / Vega-Lite

**适合：**
- 柱状图
- 折线图
- 散点图
- 热力图
- 雷达图
- 面积图
- 词云
- 数据驱动图表
- 可交互数据可视化

**要求：**
- 数据必须真实。
- 不得编造数值。
- 图表标题、单位、坐标轴必须清楚。
- 论文正式统计图仍优先 scientific-visualization / matplotlib / seaborn，然后再嵌入文档。

## 3. Infographic

**适合：**
- KPI 卡片
- 时间线
- 路线图
- SWOT
- 漏斗图
- 组织架构
- 竞赛展示页
- 项目总结图

**要求：**
- 不要做成宣传海报。
- 不能用来伪造数据仪表盘。
- 适合展示结构和摘要，不适合替代严肃统计图。

## 4. Canvas

**适合：**
- 知识图谱
- 思维导图
- 概念图
- 选题结构图
- 项目规划板
- 非线性关系图

**要求：**
- 节点数量要控制。
- 层级关系要清楚。
- 不要把所有信息塞成一张大网。

## 5. Graphviz

**适合：**
- 模块依赖
- 函数调用链
- 包引用关系
- 有向图
- 无向图
- 自动布局复杂关系

**要求：**
- 节点命名简短。
- 边关系必须真实。
- 技术依赖图应从代码或明确设计文档提取，不能猜。

## 6. Architecture

**适合：**
- 分层系统架构图
- 微服务架构
- 数据平台架构
- Web App 架构
- 项目技术路线架构
- AI 系统模块图

**要求：**
- 必须分层。
- 必须区分接入层、服务层、模型层、数据层、展示层等。
- 不要画成普通流程图。

## 7. Infocard

**适合：**
- 知识卡片
- 结论摘要
- 功能介绍
- 版本更新说明
- PPT 或报告中的重点信息块

**要求：**
- 信息少而精。
- 不要塞长段落。
- 不要替代正文论证。

## 8. PlantUML UML

**适合：**
- 类图
- 序列图
- 用例图
- 活动图
- 组件图
- 部署图
- 状态图
- 对象图

**适合场景：**
- 软件设计说明书
- 系统设计评审
- 课程设计
- 代码架构分析

## 9. PlantUML Cloud

**适合：**
- AWS、Azure、GCP、Kubernetes 等云架构
- 多云部署
- Serverless 架构
- 容器集群

**要求：**
- 不得使用不存在的云资源。
- 不要把本地项目伪装成云原生架构。

## 10. PlantUML Network

**适合：**
- 网络拓扑
- 路由器、交换机、防火墙
- 数据中心网络
- 企业网络设计

## 11. PlantUML Security

**适合：**
- 威胁模型
- 零信任架构
- STRIDE 分析
- 信任边界
- 数据流安全审计

## 12. PlantUML ArchiMate

**适合：**
- 企业架构
- 业务层、应用层、技术层对齐
- 大型系统规划

## 13. PlantUML BPMN

**适合：**
- 业务流程建模
- 网关、事件、子流程
- 审批流程
- 端到端业务链条

## 14. PlantUML Data Analytics

**适合：**
- ETL
- 数据仓库
- 数据湖
- 机器学习工作流
- 数据管道

## 15. PlantUML IoT

**适合：**
- 传感器
- 边缘计算
- 物联网网关
- 云端平台
- 数字孪生

## 16. Mindmap (PlantUML)

**适合：**
- 头脑风暴
- 知识组织
- 层级观点展示
- 项目规划
