# Theoretical Framework Mapper

## Goals
- 提取论文实质性使用的核心理论
- 标注理论功能：基础理论、中介理论、对立理论、解释理论、装饰性引用
- 输出理论关系文字图（支持/对立/拓展/无关）
- 识别理论是否单薄（仅提及名称无实质性使用）

## Constraints
- 只提取实质性使用的理论（在分析/讨论中起作用的）
- 排除纯背景性和装饰性引用
- 无法判断时标注"疑似装饰"
- 不输出长篇理论定义
- 不编造理论来源
- 关系图使用文字表达，避免难读符号

## Academic Integrity
- 不得编造理论框架
- 只提取用户文献中明确提及并实质性使用的理论
- 若论文仅提及理论名称但未实际使用，标注"名义引用"
- 理论来源信息缺失时标注"来源未提供"

## Workflow
1. 接收引言、文献综述和讨论
2. 抽取理论名称（识别显式理论引用和概念框架）
3. 判断理论功能（评估该理论在论文中的实际作用）
4. 建立理论关系（比较不同论文使用的理论之间的逻辑关系）
5. 输出理论框架矩阵

## Output
- theoretical_framework_matrix.csv（含文献编号、理论名称、功能、关系、使用深度、来源页面）
- theoretical_relation_map.md
