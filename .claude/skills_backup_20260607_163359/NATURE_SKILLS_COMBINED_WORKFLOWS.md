# Nature Skills — 与已有 Skills 组合工作流

---

## A. Nature 风格论文图件工作流

```
1. using-superpowers                    → 明确图件目标、期刊要求
2. empirical-result-extraction-auditor  → 提取真实发现，防止过度解读
3. nature-figure                        → 生成 figure contract + 绘图代码
4. reviewer-red-team-auditor            → 审稿人视角检查图件
5. word-document-processor              → 嵌入 Word 论文稿
```

---

## B. Nature 风格英文润色工作流

```
1. markitdown                           → 解析原稿
2. academic-abstract-pipeline           → 检查摘要结构
3. nature-polishing                     → Nature 风格润色
4. disciplinary-tone-auditor            → 删除夸张语言
5. grammar-correction-auditor           → 最终语法校对
```

---

## C. 引用检索与审计工作流

```
1. keyword-literature-download          → 构建文献库
2. nature-citation                      → 按可引用单元检索高质量引用
3. literature-boundary-lock             → 锁定可用文献边界
4. citation-format-syntax-auditor       → 校正引文句法
```

---

## D. 数据可用性声明工作流

```
1. using-superpowers                    → 明确数据类型和限制
2. nature-data                          → 生成声明
3. objectivity-calibration-auditor      → 检查是否过度承诺
4. word-document-processor              → 写入投稿文档
```

---

## E. 论文转 PPT 工作流

```
1. markitdown                           → 解析论文
2. summarize                            → 提炼核心结论
3. nature-paper2ppt                     → 按论文类型设计结构
4. nature-figure                        → 优化关键图件
5. word-document-processor              → 生成讲稿说明
```

---

## F. 项目申报书增强工作流

```
1. nsfc-proposal-architecture-pipeline  → 搭建申请书结构
2. objective-innovation-auditor-pipeline → 审计创新点
3. nature-figure                        → 生成技术路线图/机制图
4. nature-polishing                     → 润色英文摘要
5. word-document-processor              → 排版申报书
```

---

## G. 投稿前完整检查

```
1. nature-polishing                     → 语言检查
2. nature-citation                      → 引用核查
3. nature-data                          → 数据声明检查
4. nature-figure                        → 图件审稿人检查
5. citation-format-syntax-auditor       → 引文格式
6. grammar-correction-auditor           → 语法校对
7. objectivity-calibration-auditor      → 过度声明检查
```
