# Core Workflow — 与已有 Skills 组合工作流

---

## A. 软件开发全流程

```
1. using-superpowers              → 明确目标、边界、验收标准
2. karpathy-guidelines            → 控制执行风格，先思考，不乱重构
3. git-workflow                   → 检查分支、diff、提交策略
4. testing                        → 建立测试或最小验证
5. refactor                       → 在测试保护下做结构优化
6. docs                           → 更新 README 和开发文档
7. summarize                      → 输出变更摘要
```

---

## B. 浏览器与网页自动化

```
1. research                       → 先确定可信来源和检索问题
2. agent-browser                  → 用于探索性网页浏览
3. Playwright                     → 用于稳定、可重复的浏览器自动化
4. docs                           → 记录操作流程
5. summarize                      → 总结结果
```

---

## C. 长任务与多服务运行

```
1. tmux                           → 管理服务、日志和长任务
2. git-workflow                   → 确保修改前状态清晰
3. testing                        → 检查服务是否正常
4. docs                           → 记录启动、停止和排错方式
```

---

## D. 文献与论文写作

```
1. keyword-literature-download    → 检索和下载文献
2. markitdown                     → 解析 PDF / Word
3. summarize                      → 提取每篇文献要点
4. literature-boundary-lock       → 锁定文献边界
5. critical-literature-review-pipeline → 生成批判性综述
6. docs / word-document-processor → 整理为 Word 文档
```

---

## E. 基金与项目申报

```
1. using-superpowers              → 明确申报要求
2. brainstorming                  → 生成方案
3. research                       → 补充政策、背景、技术趋势
4. keyword-literature-download    → 构建文献库
5. nsfc-proposal-architecture-pipeline → 搭建申请书结构
6. objective-innovation-auditor-pipeline → 审计创新点
7. nature-figure                  → 生成图件
8. word-document-processor        → 排版成 docx
9. docs                           → 生成附件说明和提交清单
```

---

## F. 内容创作与发布

```
1. summarize                      → 从长文提炼核心内容
2. docs                           → 转成结构清晰的文案
3. agent-browser 或 Playwright    → 仅用于低风险发布辅助
```
