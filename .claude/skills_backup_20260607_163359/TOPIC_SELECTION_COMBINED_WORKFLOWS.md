# 论文选题方法论 — 与已有 Skills 组合工作流

---

## A. 标准论文选题工作流

```
1. using-superpowers
   明确学科、层次、截止时间、资源边界和验收标准。

2. brainstorming
   从兴趣、现实问题和已有知识中发散初始方向。

3. research
   检索政策、行业、学术趋势。

4. keyword-literature-download
   建立最小文献池，至少 20 篇可核验文献。

5. paper-topic-selection-methodology
   生成候选题、打分、收敛、MVP 预审。

6. critical-literature-review-pipeline
   对 TOP3 的文献空白做批判性验证。

7. objective-innovation-auditor-pipeline
   审计 TOP3 是否只是表面创新。

8. word-document-processor
   生成一页式定题卡 docx。
```

---

## B. 开题报告工作流

```
1. paper-topic-selection-methodology
   确定题目和研究问题。

2. critical-literature-review-pipeline
   写研究现状与研究空白。

3. nsfc-proposal-architecture-pipeline
   组织研究目标、内容和技术路线。

4. nature-figure
   生成研究框架图或技术路线图。

5. word-document-processor
   排版开题报告。
```

---

## C. 导师沟通工作流

```
1. summarize
   将候选题压缩为 3 个备选方案。

2. paper-topic-selection-methodology
   输出一页式定题卡。

3. reviewer-red-team-auditor
   模拟导师质疑。

4. docs
   生成导师沟通提纲。
```

---

## D. 数据可得性预审工作流

```
1. keyword-literature-download
   检索已有研究和数据声明。

2. nature-data
   检查公开数据和数据可用性声明。

3. paper-topic-selection-methodology
   执行 A/B/C/D 数据分级。

4. objective-innovation-auditor-pipeline
   判断题目是否因为数据不可得而需要降级。
```

---

## E. 论文申报书选题工作流

```
1. using-superpowers
   锁定申报要求和评分标准。

2. brainstorming
   生成项目方向。

3. paper-topic-selection-methodology
   筛选可执行题目。

4. nsfc-proposal-architecture-pipeline
   转化为项目申请书结构。

5. objective-innovation-auditor-pipeline
   审计创新点。

6. nature-figure
   生成路线图。
```
