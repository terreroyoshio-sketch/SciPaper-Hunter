# 创新点客观审计 — 提示词模板

以下模板可直接复制并在 Claude Code 中使用。

---

## 模板 1：完整创新点客观审计

```
请使用 objective-innovation-auditor-pipeline。以下是我的原始研究结果、
实验数据、方法说明和对比文献。请不要凭空构思创新点。
请依次完成表面创新审查、理论贡献提炼、方法学量化、应用价值锚定、
基准对比、语言净化、三点式封装和审稿人红队审查。

[在此处粘贴原始创新点草稿、研究结果、实验数据、方法说明、对比文献和应用场景]
```

---

## 模板 2：表面创新审查

```
请使用 surface-innovation-auditor。
请用"那又怎样"的评审逻辑审查以下创新点，指出哪些只是表面创新，
哪些需要补充机制价值、理论意义或基准数据。

[在此处粘贴创新点草稿和研究结论]
```

---

## 模板 3：理论创新提炼

```
请使用 theoretical-paradigm-extractor。
请基于以下研究结果和讨论内容，判断是否存在理论范式层面的贡献。
不得夸大数据，不得提出输入材料之外的理论主张。

[在此处粘贴研究结果和讨论部分]
```

---

## 模板 4：方法学创新量化

```
请使用 methodological-breakthrough-quantifier。
请从以下新方法和基准测试结果中提取可量化的方法学创新，
必须使用具体指标和性能差值，不得使用"显著提升""明显更好"等模糊表述。

[在此处粘贴新方法描述、对比方法和基准测试数据]
```

---

## 模板 5：应用价值锚定

```
请使用 translation-application-anchor。
请将以下研究结论映射到具体临床、工程、工业或社会需求上，
输出谨慎、具体、可验证的应用价值陈述。

[在此处粘贴研究结论和应用场景]
```

---

## 模板 6：跨学科创新审计

```
请使用 interdisciplinary-fusion-auditor。
请审查以下跨学科方案是否构成实质创新。
必须说明领域 B 的方法具体解决了领域 A 的哪个盲区，而不是简单拼接。

[在此处粘贴领域 A 的问题、领域 B 的方法和融合结果]
```

---

## 模板 7：基准对比创新

```
请使用 benchmark-comparison-defender。
以下是我的创新主张和两篇代表性对比论文。
请客观写出本研究相较于既有基准的具体差异、优势和仍需防御的薄弱点。

[在此处粘贴创新主张、对比论文 1、对比论文 2 和本研究结果]
```

---

## 模板 8：普适性外延价值

```
请使用 generality-extension-mapper。
请基于以下已验证结果，谨慎判断该机制或方法是否可能扩展到相关领域。
不得超出数据边界。

[在此处粘贴研究发现、验证场景和数据范围]
```

---

## 模板 9：夸张语言净化

```
请使用 hype-language-cleaner。
请删除以下创新点中的"开创性""革命性""首创""重大突破"等夸张表达，
改写为客观、克制、基于证据的学术表述。

[在此处粘贴创新点段落、基金申请创新性说明或 Cover Letter 草稿]
```

---

## 模板 10：三点式创新封装

```
请使用 three-point-innovation-packager。
请将以下已通过审计的创新主张整理为三点式结构：
1. 理论创新
2. 方法学创新
3. 应用或外延价值创新
每点以加粗主动语态结论开头。

[在此处粘贴理论创新表述、方法学创新表述和应用价值表述]
```

---

## 模板 11：审稿人红队审查

```
请使用 reviewer-red-team-auditor。
请从严苛审稿人和基金评审专家角度，审查以下三点式创新点的逻辑漏洞、
证据不足、基准缺失和外推过度问题，并提出降级或补证建议。

[在此处粘贴最终三点式创新点和支撑数据]
```

---

## 快速组合示例

### 基金申请书创新性说明

```
请按以下步骤完成：

第一步：使用 theoretical-paradigm-extractor
基于以下研究结果提炼理论创新：
[粘贴研究结果]

第二步：使用 methodological-breakthrough-quantifier
基于以下实验数据量化方法学创新：
[粘贴实验数据和基准对比]

第三步：使用 hype-language-cleaner
净化语言后，用 three-point-innovation-packager 封装

第四步：使用 reviewer-red-team-auditor 做最终红队审查
```

### SCI Cover Letter 贡献声明

```
请使用 benchmark-comparison-defender，基于以下内容：
[粘贴创新主张和对比论文]

然后使用 three-point-innovation-packager 封装为三点式贡献。

最后使用 disciplinary-tone-auditor 调整为克制语气。
```
