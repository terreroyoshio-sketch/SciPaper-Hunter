# 批判性文献综述 — 提示词模板

以下模板可直接复制并在 Claude Code 中使用。

---

## 模板 1：文献边界锁定

```
请使用 literature-boundary-lock。以下是我已经人工核实的文献题录和摘要。
你只能基于这些文本进行综合，不得虚构任何作者、年份、题名、DOI、期刊或结论。
如果某项信息缺失，请标注"在提供的文本中未找到相关信息"。

[在此处粘贴已核实的文献题录和摘要]
```

---

## 模板 2：主题聚类

```
请使用 literature-theme-clustering。
请将以下文献按 3 到 4 个概念性主题分组，并生成主题驱动的综述段落。
禁止采用"作者 A 说、作者 B 说"的流水账结构。

[在此处粘贴文献摘要列表]
```

---

## 模板 3：国内外研究现状对比

```
请使用 domestic-international-paradigm-comparator。
以下文献已按国内和国际分组。请客观比较国内外研究范式、研究重点、优势、
局限和协同性空白。所有判断必须来自提供文本。

国内文献：
[粘贴国内文献]

国际文献：
[粘贴国际文献]
```

---

## 模板 4：学术争议梳理

```
请使用 academic-disagreement-mapper。
请从以下文献中识别相互矛盾的结果、竞争性理论或方法分歧，
并客观写成一个学术争议段落。

[在此处粘贴文献摘要和结果摘录]
```

---

## 模板 5：方法论局限

```
请使用 methodological-limitation-synthesizer。
请综合以下文献的方法和局限性，写出当前领域的共性方法局限。
不得夸大前人不足。

[在此处粘贴文献方法部分和局限性部分]
```

---

## 模板 6：段落桥接

```
请使用 paragraph-logic-bridge。
请为段落 A 和段落 B 写一个学术化逻辑桥接句，
体现二者之间的对比、递进、转化、因果或范围收缩关系。
不要使用"此外""接下来"等生硬过渡词。

段落 A：
[粘贴段落A]

段落 B：
[粘贴段落B]
```

---

## 模板 7：漏斗排序

```
请使用 funnel-logic-sorter。
请将以下主题段落按照"宏观背景—主流方法—细分问题—尚未解决的问题"
的漏斗结构重新排序，并输出递进清晰的文献综述文本。

[在此处粘贴已综合的主题段落]
```

---

## 模板 8：客观性校准

```
请使用 objectivity-calibration-auditor。
请将以下综述评价段落与原始摘要逐条比对，
标记任何过度贬低或缺乏文本支撑的批评，
并改写为客观、中立的学术表述。

原始摘要：
[粘贴原始摘要]

评价段落：
[粘贴评价段落]
```

---

## 模板 9：研究空白界定

```
请使用 research-gap-definer。
请根据以下文献综述、争议和方法局限，写出一个高信息密度研究空白段落，
必须包含"空白""尚未解决"或"关键瓶颈"等表达，
并与拟开展研究目标建立逻辑桥接。

[在此处粘贴文献综述初稿 + 学术争议段落 + 方法局限段落 + 拟研究目标]
```

---

## 模板 10：引文句法与格式校对

```
请使用 citation-format-syntax-auditor。
请优化以下文献综述中的引文句法和格式。
不得更改任何作者姓名、年份或引用来源，
只能调整句子结构、引用位置和行文流畅度。

引文格式要求：[APA / GB/T 7714 / 数字编号制]

[在此处粘贴文献综述草稿]
```

---

## 模板 11：完整闭环综述流水线

```
请使用 critical-literature-review-pipeline。
以下是我人工核实后的 20 到 30 篇核心文献题录与摘要。
请严格锁定数据边界，依次完成：
1. 主题聚类
2. 国内外研究范式对比（如已分组）
3. 学术争议梳理
4. 方法论局限性分析
5. 漏斗排序
6. 段落桥接
7. 客观性校准
8. 研究空白界定
9. 引文句法校对

不得虚构任何引文信息。

研究主题：[填写]
目标用途：[SCI 综述 / 学位论文 / 国自然 / 项目申报]
引文格式要求：[填写]
拟研究目标：[填写]

[在此处粘贴已核实的文献题录和摘要]
```
