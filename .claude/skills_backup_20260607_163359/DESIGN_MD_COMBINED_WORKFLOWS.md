# Design MD Collection — Combined Workflows

---

## A. 新产品官网设计工作流

```
1. Using-Superpowers
   明确产品、用户、页面目标、技术栈和验收标准。

2. Brainstorming
   生成 2-3 套信息架构方案。

3. design-md-collection
   选择合适视觉系统参考，生成 DESIGN.md。

4. Frontend Design
   细化设计系统和组件规范。

5. React / Tailwind / shadcn/ui
   实现页面。

6. Playwright
   做视觉和交互测试。
```

## B. SaaS 后台系统工作流

```
1. Matt Pocock grill-me
   拷问业务对象、用户角色和核心操作。

2. design-md-collection
   选择 Linear/Notion/Airtable/Slack 类参考方向。

3. to-prd
   整理功能需求。

4. to-issues
   拆成垂直切片任务。

5. refactor / testing
   实现并验证。
```

## C. AI 工具或开发者文档站工作流

```
1. research
   调研竞品和开发者文档结构。

2. design-md-collection
   选择 Vercel/Supabase/Mintlify/Cursor/Claude 类参考方向。

3. docs
   生成信息架构和文档结构。

4. agent-browser
   核查实际页面展示效果。

5. Playwright
   测试导航、搜索和响应式布局。
```

## D. 科研项目展示页面工作流

```
1. nsfc-proposal-architecture-pipeline
   提炼项目研究内容。

2. objective-innovation-auditor-pipeline
   筛选真实创新点。

3. nature-figure / scientific-visualization
   生成专业图表。

4. design-md-collection
   生成产品级展示页面视觉系统。

5. ppt-master
   同步生成展示 PPT。
```

## E. 竞赛路演/项目演示 PPT 工作流

```
1. Brainstorming
   确定叙事结构。

2. design-md-collection
   选择 Apple/Vercel/Linear/Stripe 等启发风格。

3. nature-figure
   处理科研图。

4. ppt-master
   生成可编辑 PPT。
```

## F. 现有页面 UI 改造工作流

```
1. agent-browser
   查看页面截图或运行状态。

2. design-md-collection
   诊断风格问题并选择参考设计系统。

3. refactor
   不改业务逻辑，只改 UI 结构和样式。

4. Playwright
   测试视觉回归和响应式。
```

## G. 项目申报书空间图+UI 工作流

```
1. nsfc-proposal-architecture-pipeline
   明确研究内容框架。

2. technical-route-blueprint-planner
   设计技术路线图。

3. design-md-collection
   参考 Vercel/Apple 风格做申报书在线展示。

4. geopandas / geomaster
   生成空间数据图。

5. ppt-master
   生成答辩 PPT。
```
