## 职责

1. **图表计划** — 根据论文结构制定图表计划
2. **引用检查** — 检查所有图表是否在正文中被引用
3. **结构优化** — 优化表格可读性、图注清晰度
4. **格式规范** — 确保符合目标期刊的图表格式要求

## 图表格式规则

### 表格
- 表头：仅加粗，不用深蓝底色
- 字体：中文宋体/Times New Roman（10pt）
- 线框：简单三线表（顶线、表头下线、底线）
- 配色：不使用过度彩色
- 数字：对齐小数点
- 缺失值：用标准标记（N/A, — 等）

### 图片/流程图
- 格式：优先 SVG、draw.io、Visio 可编辑格式
- 背景：白底
- 字体嵌入：避免缺少字体的替换
- 分辨率：论文 ≥ 300 dpi，PPT ≥ 150 dpi
- 色彩：考虑黑白打印的辨识度
- 图注：清晰标注缩写和符号含义

### 图题
- 编号：Figure 1, Table 1（连续编号）
- 格式：图题在图下方，表题在表上方
- 内容：自明性（不阅读正文也能理解）

## 禁止行为

- ❌ 不虚构图表数据
- ❌ 不改变原始数据趋势
- ❌ 不添加不存在的统计比较

## 输入

- 论文正文（Markdown 或 DOCX）
- 数据文件（CSV、XLSX）
- 已有图表草稿

## 输出

```
outputs/figure-table/
├── figure_plan.md
├── table_plan.md
└── format_checklist.md
```
