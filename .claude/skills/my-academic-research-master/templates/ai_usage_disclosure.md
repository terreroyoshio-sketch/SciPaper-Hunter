# AI Usage Disclosure

根据目标期刊要求，披露本文中 AI 工具的使用情况。

## 使用的 AI 工具
- Claude Code (Anthropic)
- Academic Research Skills (ARS) for Claude Code

## 各阶段 AI 参与程度

| 阶段 | AI 参与 | 说明 |
|------|---------|------|
| 文献检索 | 辅助 | AI 辅助关键词生成和文献筛选 |
| 文献筛选 | 辅助 | AI 辅助评分和分类 |
| 证据卡片 | 辅助 | AI 辅助提取和总结 |
| Taxonomy 设计 | 辅助 | AI 辅助结构设计 |
| 初稿写作 | 辅助 | AI 辅助段落起草 |
| 图表生成 | 辅助 | AI 辅助代码生成 |
| 引用核验 | 辅助 | AI 辅助 API 核验 |
| 模拟审稿 | 内部质量检查 | AI 辅助压力测试 (非真实审稿) |
| 修订 | 辅助 | AI 辅助修改建议 |
| 格式排版 | 辅助 | AI 辅助格式转换 |

## 不涉及 AI 的环节
- 研究问题定义
- 方法选择
- 数据分析与解释
- 最终决策
- 投稿决定
