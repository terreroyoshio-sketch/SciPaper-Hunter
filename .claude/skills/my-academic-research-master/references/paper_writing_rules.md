# Paper Writing Rules

**文件:** `references/paper_writing_rules.md`
**用途:** 论文写作阶段的格式、语言和结构标准。

---

## 段落规则

1. 每段必须有中心句（第一句或第二句）
2. 每段至少一个证据来源（citation）
3. 不写没有来源的强判断
4. 不用文献摘要拼接正文
5. 不用公众号语言
6. 不用过多项目符号（每节 ≤3 个）
7. 不写空泛过渡（"As mentioned above" 等）
8. 每段结尾应有意义说明或限制

## 结构规则

默认论文结构:
```
1. Introduction: Hook → Gap → Contributions → Roadmap
2. Related Work / Background
3. Method / Taxonomy
4. Main Body (2-5 sections)
5. Experiments / Comparative Analysis
6. Discussion / Challenges
7. Future Directions
8. Conclusion
```

## 写作质量规则

1. 首次使用缩写必须全称
2. 每个图表必须在正文中被引用
3. 术语必须全文一致
4. 数字和单位之间加空格（"10 kg" 不是 "10kg"）
5. 引用格式必须全篇统一
6. 不出现"This paper" — 使用"This work"或"This survey"
7. 不使用"Firstly, Secondly, Lastly"模式
8. 每个 Section 必须有其存在的理由
