# Quality Gates

**文件:** `references/quality_gates.md`
**用途:** 硬性质量闸门，未通过不进入下一阶段。

---

## Gate 1: 文献闸门

**位置:** Phase 2 → Phase 3（文献筛选完成 → 进入证据卡片阶段）
**通过条件（全部必须满足）:**

- [ ] 核心主题每个子方向至少 5 篇相关文献
- [ ] 每个核心结论至少 2 个来源支撑
- [ ] A 类文献必须有 evidence card
- [ ] 关键文献必须有 DOI 或稳定 URL
- [ ] 未核验文献不能支撑核心结论
- [ ] 每个子方向都有至少 1 篇 A 类文献
- [ ] 排除文献记录筛选理由

---

## Gate 2: 引用闸门

**位置:** Phase 7 → Phase 8（引用核验完成 → 进入审稿阶段）
**通过条件（全部必须满足）:**

- [ ] 0 条编造引用
- [ ] 0 条编造 DOI
- [ ] 所有正文引用都能在 references.bib 中找到
- [ ] 所有关键数据都有来源
- [ ] 所有引用和句子论点基本匹配
- [ ] BibTeX 中无不使用的条目
- [ ] 未核验引用 ≤ 总数的 10%

---

## Gate 3: 实验闸门

**位置:** 有实验时，Phase 6 → Phase 7
**通过条件（全部必须满足）:**

- [ ] 没有运行的实验不能写入结果
- [ ] 没有保存日志的训练不能写入结果
- [ ] 没有随机种子不能写稳定性结论
- [ ] 没有对照实验不能写优于某方法
- [ ] 没有统计检验不能写显著提升
- [ ] 图表必须来自真实数据文件
- [ ] 失败实验没有被删除
- [ ] 没有只报告最好结果

---

## Gate 4: 语言闸门

**位置:** Phase 9 → Phase 10（修订完成 → 最终导出）
**通过条件（全部必须满足）:**

- [ ] 删除夸张表达
- [ ] 删除公众号表达
- [ ] 删除空泛贡献
- [ ] 删除没有证据的创新点
- [ ] 删除模板化 AI 句式
- [ ] 删除没有信息量的段落
- [ ] 删除"众所周知""具有重要意义"等空话
- [ ] 中文符合论文规范 / 英文符合期刊语气

---

## Gate 5: 伦理闸门

**位置:** Phase 10 最终导出前
**通过条件（全部必须满足）:**

- [ ] 涉及人类受试者 — 检查伦理审批
- [ ] 涉及儿童、学生、课堂数据 — 检查知情同意
- [ ] 涉及隐私数据 — 检查匿名化
- [ ] AI 使用情况按目标期刊要求完整披露
- [ ] 模拟审稿不冒充真实同行评审
- [ ] 已填写 `ai_usage_disclosure.md`
- [ ] 已填写 `submission_checklist.md`
- [ ] 所有 `[UNVERIFIED]` 标记已处理
