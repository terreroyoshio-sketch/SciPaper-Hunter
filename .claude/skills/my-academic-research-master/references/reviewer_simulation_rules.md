# Reviewer Simulation Rules

**文件:** `references/reviewer_simulation_rules.md`
**用途:** 模拟审稿的执行标准。

---

## 审稿人角色

| 角色 | 检查重点 |
|------|---------|
| 主编 (EIC) | 整体质量、投稿风险、符合期刊 scope |
| R1 领域审稿人 | 文献覆盖、分类合理性、创新性 |
| R2 方法审稿人 | 方法论严谨性、实验设计、统计方法 |
| R3 引用核验审稿人 | 引用真实性、论点-引用匹配、数据来源 |
| R4 魔鬼代言人 | 故意质疑核心假设、找夸大、找漏洞 |

## 评分维度 (1–10)

1. 研究问题清晰度
2. 文献覆盖度
3. 结构完整性
4. 分类合理性
5. 批判性分析
6. 方法深度
7. 引用可靠性
8. 图表质量
9. 语言质量
10. 投稿风险

## 审稿结论

| 结论 | 含义 |
|------|------|
| Accept for internal draft | 内部审查通过，可进入下一阶段 |
| Minor revision | 小幅修改后可进入最终检查 |
| Major revision | 需要重大修改后才能继续进行 |
| Reject as current draft | 当前版本不适合继续推进，需要重新设计 |

## 限制

1. AI 审稿结论不能写"可直接投稿"
2. 除非 citation audit + ethics check + format check 全部通过
3. 每轮必须对比上一轮问题是否修复（regression check）
4. 不应该在未阅读修改的情况下直接给 Accept
