## 来源核查

- [ ] 原始文件已保留（未覆盖、未删除）
- [ ] 所有信息来源已记录（URL / 文件路径 / 参考文献）
- [ ] 网页信息标注了访问日期
- [ ] 关键网页已截图保存
- [ ] PDF 信息标注了页码
- [ ] 表格分析保留了原始版本

## 数据核查

- [ ] 图表基于真实数据（非虚构）
- [ ] 无编造的统计量（p 值、均值、百分比）
- [ ] 异常值已标注，未擅自删除
- [ ] 数字有业务或研究背景解释

## 文档核查

- [ ] PPT 每页一个核心点
- [ ] 文档未改变原意
- [ ] 夸张表达已删除（"极大提升""颠覆性"等）
- [ ] 专有名词未被替换
- [ ] 术语全文统一
- [ ] AI 味模板句已删除

## 隐私核查

- [ ] 无身份证号、手机号、完整地址
- [ ] 无账号密码
- [ ] 学生 / 患者数据已脱敏
- [ ] 合同敏感条款已提醒人工复核

## 格式核查

- [ ] 中文正文：宋体小四（默认）
- [ ] 英文正文：Times New Roman
- [ ] 表格：三线表，表头加粗
- [ ] 页脚：仅保留页码
- [ ] PPT 字号清晰（标题 ≥ 28pt，正文 ≥ 18pt）

## 交付判断

- [ ] ✅ 可以交付
- [ ] ⚠️ 有条件交付（见备注）
- [ ] ❌ 不能交付（见原因）

## 以下内容不能直接使用

1. 法律条款摘要 — 需人工核实原文
2. 财务数字 — 需人工对账
3. 医疗建议 — 需专业人员审核
4. 学术引用 — 需核验 DOI 和原文
5. 自动化脚本 — 需安全审查后启用
6. 图像生成结果 — 需人工确认无虚假细节
