# PPT Final Checklist

## File safety

- [ ] Original file backed up
- [ ] New version saved separately (not overwriting the original)
- [ ] No original file overwritten

## Format

- [ ] 16:9 ratio
- [ ] Fonts consistent across all slides
- [ ] Title sizes consistent
- [ ] Body text readable (≥ 18 pt for Chinese, ≥ 16 pt for English)
- [ ] No text overflow on any slide
- [ ] No missing images (all paths valid)
- [ ] No formula rendering errors
- [ ] No broken charts

## Research content

- [ ] No fabricated data
- [ ] No fabricated citations
- [ ] No unsupported claims (every claim has evidence)
- [ ] All figures have source notes
- [ ] All tables have source notes
- [ ] Key results match original data (not altered)
- [ ] Limitations included when needed
- [ ] Acknowledgments section present when applicable

## Visual quality

- [ ] One core message per slide
- [ ] Clean academic style (not decorative)
- [ ] No excessive bullet points (> 5 per slide)
- [ ] No dark blue table headers (unless template-required)
- [ ] No decorative clutter or chart junk
- [ ] Figures are readable when projected
- [ ] Color palette is restrained and consistent

## Output

- [ ] PPTX opens correctly (tested)
- [ ] PDF export checked if required
- [ ] Speaker notes checked if required
- [ ] Final audit report generated
