## Installation

Official installation steps:

1. Open Microsoft PowerPoint.
2. Go to the **Home** tab.
3. Click **Add-ins** (or **Get Add-ins** in some versions).
4. Search for "ChatGPT".
5. Select the official OpenAI add-in.
6. Click **Add**.
7. Sign in with your **OpenAI account** (any tier).

**Source**: Multiple tech outlets citing OpenAI's May 2026 announcement; official page at `chatgpt.com/apps/powerpoint`.

## Supported input formats

- Natural language prompts
- Notes and outlines
- Word documents (.docx)
- PDF files
- Spreadsheets (.xlsx)
- Images
- Existing PowerPoint decks (.pptx)
- Connected services: Gmail, Outlook, SharePoint

## Output

- All generated slides are **fully editable** in PowerPoint.
- Text is rendered as native PowerPoint text boxes.
- No output is flattened as images.

## Beta limitations

Based on OpenAI's published notes and independent reporting:

1. **Complex formatting not fully supported**: Custom templates, intricate slide masters, and non-standard fonts may not render correctly.
2. **Can make mistakes**: ChatGPT may change or delete content if the prompt is ambiguous. Users must verify all numbers, claims, and slide content.
3. **No ChatGPT add-in for Word yet**: Only PowerPoint and Excel have official add-ins at this time.
4. **Potential admin restrictions**: Enterprise, Business, and Edu workspace administrators may restrict or disable add-in installation.
5. **Review before sharing**: OpenAI explicitly recommends reviewing all changes before distributing a deck.

## Data privacy

- **Business, Enterprise, Edu, Teachers** accounts: data shared via the add-in is **not used** for model training by default.
- Workspace admins can control add-in access and data-sharing policies through admin settings.
- Users on Free or Plus plans should review their ChatGPT data-sharing settings before uploading sensitive materials.
