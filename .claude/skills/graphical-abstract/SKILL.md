# Graphical Abstract — 图形摘要

## 职责
用**一张大场景图**传达论文的一句话结论：主体对象 → 过程/机制 → 关键结果。5 秒内可读。

## 先立后画
1. **先写一句核心信息**（主语+动词+对象+方向性结论），经用户确认后再构图。
2. 明确**目标期刊**：GA 尺寸/比例/文字限制各刊差异极大——**未确认目标期刊要求前不出终稿**；禁报未经核实的期刊规格数字。
3. 列出必须出现在图中的 3–6 个要素（对象/过程/结果），其余全部砍掉。

## 构图范式
- **场景主体**（40–60% 面积）：机制示意/装置/生态系统等大对象（用几何简化，允许 80% 完成度后交 SVG 二次编辑）
- **过程层**：2–4 个方向明确的过程箭头（标注动词，不装饰）
- **结果层**：1–2 个真实数据小图 or 关键数值（必须真实）
- 阅读路径单一（左→右 或 环状），不得散点式铺开

## 输入与证据
- 论文摘要+结论段；关键结果小图来自真实数据文件
- 合成/占位元素必须标 PLACEHOLDER；概念示意标 schematic

## 渲染器
- matplotlib 复合（大对象 primitives + 内嵌 axes）；复杂 hero 场景 → 导出 SVG → Illustrator/Inkscape 收尾
- 参考样式：`nature-figure-style`（几何美学）、`references/figure_style_catalog.md`（参考图1 的整页组图思路）

## 禁用
- 图标堆砌（emoji/icon 素材）、渐变卡片、Canva 信息图风、装饰性发光
- 超过 2 种强调色抢注意力

## 输出与 QA
- SVG + PDF + PNG + 灰度 + 缩印预览；**必经 `figure-quality-gate`**
- 目检附加两问：5 秒能说出核心信息吗？去掉任意一个要素信息是否缺失？

## 失败条件
- 核心信息句无法收敛 → 回用户确认
- 目标期刊规格未确认（可出草稿，标 DRAFT，不得称终稿）
