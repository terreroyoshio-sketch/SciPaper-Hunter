# Scientific Flowchart — 算法流程图

## 两条通道（先选通道再画）

**通道 A · 一般算法流程（工程/CS/数据流水线）**
- 语义容器 + 正交布线；节点尺寸差异化（粗细/大小承载权重）；
- 分支用分叉结构（竖干线 + 横总线 + 分支），不用 N 条斜线；
- 循环用回流箭头（虚线语义），条件用标注菱形/分支标签。

**通道 B · 数学建模类算法（数模/运筹/几何算法）**
- 优先**几何叙事**：用与数学模型对应的几何对象表达算法阶段——点/观测站/射线/线段/虚线/夹角/弧线/多边形/可行域/凸包/最小包围圆/等距线/半透明交叠/轨迹/候选点/距离标注/角度标注；
- 视觉信息 ≥60% 来自几何关系，文字极简；**不是"把算法文字装进不同形状"**。

> 背景：原《制图提示词》把"几何叙事"写成全局绝对规则，2026-09-28 修正为**分场景建议**——通道 A 允许语义容器，仅禁止无语义模板堆叠（默认 Mermaid/SmartArt/卡片堆/全同尺寸节点/纯文字节点占主体）。

## 渲染管线（两通道相同）
1. **布局**：`graphviz`（dot，本机 v14.1.3 已实测）计算节点坐标——`DOT 只负责布局`；复杂约束可用 `rank=same` 分层。图结构可用 `networkx` 生成 DAG。
2. **呈现**：导出布局坐标 → `matplotlib` 自绘节点/边（统一色族、圆角策略、箭头语义、标签按中文宽度模型断行）。
3. **兜底**：`networkx.multipartite_layout / spring_layout` + 自绘。

## 硬性禁止
- graphviz / mermaid **默认皮肤直接交稿**；
- 全节点同尺寸同颜色、所有箭头同一样式；
- 无法解释含义的箭头；装饰性图标。

## 科学正确性
- 每个节点/分支必须能指回论文/代码中的真实步骤；复杂度标注、迭代次数等必须来自实际实现。
- 通道 B：几何对象必须与论文模型一致（可行域边界、约束方向不得画反）。

## 输出与 QA
- 输出：SVG + PDF + PNG + 灰度 + 缩印预览；**必经 `figure-quality-gate`**。

## 失败条件
- 算法描述不足以确定分支/循环结构且用户无法补充
- 几何叙事通道下用户提供不了数学模型（退回通道 A 并说明）
