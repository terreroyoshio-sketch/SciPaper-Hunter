# Multipanel Compositor — 多面板复合编排

## 职责边界
**只做编排**：布局、面板标签、统一视觉系统、跨面板对齐、整体导出与验收。
各面板内容由对应家族技能负责（数据图→figurelab/academic-figure-skill；路线图→technical-route-diagram；地图→geospatial-figure；示意→mechanism-schematic 等）。

## 编排规则
1. **先定版式再画面板**：GridSpec（可用嵌套 GridSpec/subgridspec）确定网格与跨格（spanning）面板；写出每个面板的目标尺寸（mm）——面板按最终印幅设计，不靠后期缩放。
2. **面板标签**：a / b / c…（或 ① ②）左上角，加粗；全图统一字号与偏移；标签不进入面板内部内容区。
3. **统一视觉系统**：全图一套 rcParams（字体/线宽/字号）；同一语义（如"观测 vs 模拟"）跨面板同色同线型；一个面板的调色板不得自创新色族。
4. **图例策略**：≥2 个面板共享同一编码 → 全图一个共享图例（底部/右侧通栏）；编码不复用 → 各面板自带；**禁止重复冗余图例**。
5. **反冗余**：一个面板一个信息；hero 面板（主结果）占最大面积并成为视觉第一落点（可参考已装 `academic-figure-skill` 的 multipanel-layout 参考）；
6. **对齐**：共享轴域的面板共享轴（`sharex/sharey`）；等高面板对齐基线；留白（wspace/hspace）显式设定。
7. **空面板**：宁可重排 GridSpec，不留空位。

## 组装流程
1. 收集各面板图（函数级：每个面板一个 draw 函数，接收 ax）
2. 先单面板冒烟（字号/裁剪），再整体组装
3. 整体导出与 **`figure-quality-gate`**（整图 gate 一次；单面板若单独交付再各自 gate）
4. 目检：跨面板对齐、标签顺序、共享图例是否覆盖全部编码

## 失败条件
- 面板数量与信息结构不匹配（为凑网格加面板）→ 回用户减面板
- 面板间单位/量纲不一致且未加分区说明
