# H1 Rescoped: Exploration Question

**审查日期：** 2026-06-07
**用途：** 将 H1 从"临床增益"收缩为稳的探索性回顾性比较

---

## 原 H1

在呼吸配合不佳（屏气指令执行评分≤3/5）的腹部增强MRI患者中，GRASP序列是否能在图像质量评分和病灶-肝对比噪声比（CNR）上非劣于传统屏气3D-T1梯度回波序列？

## 为什么原 H1 过大

| 问题 | 原因 |
|------|------|
| "非劣效性"设计不合 | 非劣效性检验需要预定义非劣效界值（如-0.5分量表）和基于界值的样本量估计，当前无 pilot 数据 |
| "呼吸配合不佳"缺少可操作定义 | 原始定义依赖"屏气指令执行评分"，在回顾性数据中不可获取 |
| 题目暗示"临床增益" | 图像质量和 CNR 是替代指标（surrogate outcome），不是临床结局 |
| "病灶-肝 CNR"可能不可靠 | CNR 依赖 ROI 放置一致性，且病灶类型、大小、位置不同 CNR 变异大 |
| 配对设计前提不确定 | 同一患者是否同时有两个序列不可知 |
| 50 例目标无依据 | 无 pilot 数据或文献报道的效应量支撑 |

## 收缩后的 H1

**暂定题目：**
自由呼吸 GRASP 动态增强 MRI 对呼吸配合不佳患者动脉期图像质量和运动伪影的影响：一项单中心回顾性探索性研究

**研究问题（PICO 格式）：**

在腹部增强 MRI 检查中、传统屏气 3D-T1 序列图像显示中度以上运动伪影（方案 B 定义的评分≥3/5）的患者中，GRASP 序列（自由呼吸径向采集）是否在图像质量 5 分量表评分和动脉期 CNR 上优于同一患者的传统屏气 3D-T1 序列？

**研究设计：** 单中心、回顾性、自身配对（同患者两序列）、探索性研究

**统计方法：** 配对 Wilcoxon 符号秩检验（主要） + 配对 t 检验（CNR 定量），ICC 评估读者间一致性

**样本量：** 依据可得样本量（convenience sample），不下预先功效计算的结论

## 不再声称的内容

1. ❌ 不再使用"非劣效性"设计
2. ❌ 不再声称"临床增益"或"临床获益"
3. ❌ 不涉及病灶检出率比较
4. ❌ 不推导到诊断信心改变
5. ❌ 不声称优于现有标准，只报告序列间差异
6. ❌ 不用预先样本量估计支撑功效

## 当前只允许声称的内容

1. ✅ GRASP 与传统屏气 3D-T1 在呼吸不佳患者中的图像质量评分差异
2. ✅ GRASP 与传统屏气 3D-T1 的动脉期 CNR 差异
3. ✅ 两个序列的运动伪影程度分布差异
4. ✅ 探索性亚组分析（不同伪影严重程度分层的差异）

**注意：** 上述所有差异只报告方向和效应量，不写优效性结论。

## 下一步需要补充的数据

1. PACS 预查：确认至少 20-30 例有 GRASP+传统屏气 3D-T1 两条序列的患者
2. 确认同一患者两个序列是否在同一次检查中完成
3. 获取传统屏气序列的 DICOM 图像，用于运动伪影评分预测试
4. 至少 2 名读片者完成 ICC 预测试（至少 10-15 例）
5. 如果回顾性配对不可行，改为组间比较设计（需要倾向评分匹配计划）
