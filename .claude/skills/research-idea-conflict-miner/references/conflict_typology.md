# Conflict Typology

**用途：** 文献冲突类型学定义和判断规则。

## 8 种冲突类型

### 1. conclusion_conflict（结论冲突）
同一变量、模型或治疗策略在不同研究中结论不一致。
- **判断标准：** A 说有效，B 说无效或价值有限
- **排除假冲突：** 检查样本量、结局定义、人群差异

### 2. population_conflict（人群冲突）
同一方法在不同人群中结论不同。
- **判断标准：** 高危人群有效 / 低危无效；亚组出现相反趋势
- **转化方向：** 亚组分析 / 人群限定

### 3. method_conflict（方法冲突）
不同方法在同一问题上结论不一致。
- **判断标准：** 深度学习指标好 / 传统模型更稳定
- **转化方向：** 方法比较研究

### 4. mechanism_conflict（机制冲突）
一个机制解释 A 现象但解释不了 B 现象。
- **判断标准：** 理论预测与实际观察不符
- **转化方向：** 机制验证研究

### 5. scenario_conflict（场景冲突）
公开数据表现好 / 真实场景表现差。
- **判断标准：** benchmark 高但临床部署效果差
- **转化方向：** 外部验证 / 域适应

### 6. metric_conflict（指标冲突）
不同指标指向不同结论。
- **判断标准：** AUC 高但校准差 / 敏感性高低特异性低
- **转化方向：** 多维度评估

### 7. no_conflict_found
未发现需要验证的冲突。

### 8. insufficient_information
现有信息不足以判断冲突。

## 冲突真伪判断流程

```
是否有样本量差异？         → 是 → 标记方法偏差
是否有结局定义差异？       → 是 → 标记定义差异
是否有人群异质性？         → 是 → 优先亚组分析
是否来源于真实世界差异？   → 是 → 外部验证问题
以上都不是                → 可能是真科学问题
```
