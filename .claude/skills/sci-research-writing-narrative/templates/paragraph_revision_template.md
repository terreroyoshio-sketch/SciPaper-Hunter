## 3. Main problems

Check all that apply:

- [ ] Logic unclear — the reader cannot follow the argument
- [ ] Claim unsupported — no evidence provided for the assertion
- [ ] Too descriptive — lists data/observations without interpretation
- [ ] Too much passive voice — heavy, hard to read
- [ ] Too much *we* — every sentence starts with "We"
- [ ] Overclaim — claim stronger than evidence justifies
- [ ] Citation missing — a claim that needs reference
- [ ] Citation fabricated — author/DOI/year cannot be verified
- [ ] Paragraph too long — multiple messages competing
- [ ] Result before conclusion — figure/table described before the claim
- [ ] Repetition — says what was already stated in a previous paragraph
- [ ] First sentence does not announce the paragraph's function
