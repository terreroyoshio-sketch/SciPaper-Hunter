# Mechanism Schematic — 机制示意图

## 职责
用**几何构图**表达过程机理：区域（介质/层）→ 物理对象 → 通量/过程箭头 → 标注。文字极简，图形为主角。

## 结构范式
1. **区域带**：按介质分层（如 大气 / 地表 / 根区 / 含水层；或 细胞外 / 膜 / 胞内），可用浅色底或边界线分区，不用重填充。
2. **物理对象**：树/太阳/坡面/设备用**简化几何**（圆、多边形、折线）表达；复杂 hero 场景做到 80% 即止，允许导出 SVG 后交 Illustrator/Inkscape 手工收尾（沿用 nature-figure-style 的经验，不得硬写百行 Bezier）。
3. **通量箭头**：方向 = 实际过程方向（蒸散向上、下渗向下、径流沿坡）；通量大小可用线宽梯度；过程箭头与状态量（储库方框）区分样式。
4. **注释**：术语贴对象旁 1–2 倍对象高；带单位；引线要短、不交叉。

## 输入与证据要求
- 机制描述/教材或论文中的过程定义；**不得凭想象补充物理过程**
- 示意图必须标注 schematic / 示意图（反造假规则）
- 数量级若标注，必须有来源

## 渲染器
- 首选 matplotlib primitives（`patches` + `FancyArrowPatch`；复杂箭头场用 `annotate`/`quiver`）
- 涉及光路/光子/芯片 → 转 `nature-figure-style`
- 3D 结构 → 转 `scientific-3d`

## 视觉规则
- 低饱和分区色；同一物理量全图同色；灰度可辨（线型/填充图案冗余）
- 箭头线宽：过程 > 边界；虚线仅用于辅助/反馈
- 白底；无渐变卡片、无 emoji、无装饰图标（《制图提示词》§44 禁用项仍有效）

## 输出与 QA
- SVG + PDF + PNG + 灰度 + 缩印预览；**必经 `figure-quality-gate`**；示意标注必须存在（否则 FAIL）。

## 失败条件
- 机理描述不完整且无法从文献确认 → 停手，列出缺失项
- 用户要求"看起来复杂一点" → 拒绝装饰性添加
