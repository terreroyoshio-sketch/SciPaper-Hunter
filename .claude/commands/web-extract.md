# /web-extract — 网页提取与调研整理

## 适用场景
网页内容提取、来源整理、调研摘要生成。

## 输入要求
- URL 或网页内容
- 提取目标（核心观点 / 数据 / 图表）
- 是否用于决策（决定是否截图）

## 调用模块
`office-productivity-workbench` → `web-extract`

## 工作流
1. 打开网页
2. 提取标题、作者、日期、来源
3. 提取核心观点和数据
4. 如用于决策，截图保存
5. 记录访问日期
6. 输出摘要和来源日志

## 输出文件
```
outputs/web_extract/
├── web_summary.md
├── source_log.csv
├── screenshots/（如有）
└── decision_notes.md
```

## 禁止事项
- 不把网页摘要当成事实本身
- 不绕过登录权限
- 不抓取无权访问的内容
- 价格/政策/时间信息必须标注访问日期

## 验收标准
- [ ] URL 已记录
- [ ] 访问日期已记录
- [ ] 动态页面已截图
- [ ] 无法访问的页面已写明原因
