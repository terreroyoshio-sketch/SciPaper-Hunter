# /pacs-precheck — 医学影像 PACS 预查方案

## 用途
执行医学影像 PACS 预查，确认数据可得性和字段结构。

## 适用范围
- PACS 系统数据预查
- 影像数据可得性确认
- 字段结构验证

## 调用流程

1. **明确查询需求** — 病种、时间范围、影像模态、目标字段
2. **字段确认** — 列出需要导出的字段（不导隐私字段）
3. **数量确认** — 符合条件的病例数和影像数
4. **可得性确认** — 各字段的填写完整率
5. **模板输出** — 生成放射科查询请求

## 硬性约束

- ❌ 不导出隐私字段（姓名、身份证号、手机号、住址、完整住院号）
- ❌ 不导出原始 DICOM 文件
- ❌ 只做数量和字段可得性确认
- ❌ 不写论文正文
- ❌ 不进入 Stage 6（论文撰写阶段）
- ❌ 不虚构 PACS 查询结果

## 输出

```
05_constraints/
├── pacs_precheck_plan.md                  # 预查方案
├── pacs_query_field_list.csv              # 查询字段列表
├── pacs_precheck_request_to_radiology.md  # 放射科查询请求
└── pacs_precheck_result_template.csv      # 结果模板
```
